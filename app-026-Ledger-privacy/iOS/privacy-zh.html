隐私政策

最后更新：2026-08-01

「决断」（英文名 Verdict，以下简称"本应用"）是一款纯本地运行的个人决策日记工具。我们把隐私视为产品的第一性原则，不是加分项。
核心承诺：本应用不联网收集任何数据、无账号系统、无服务器、无广告、无追踪。您的所有信息只保存在您的设备本地，或（若您主动开启 iCloud 同步）您自己的 iCloud 私有域。

一、我们收集什么

什么都不收集。

更具体地讲：

  • 没有用户账号系统。您无需注册，无需登录。
  • 没有服务器。开发者这一端不存在存储您数据的任何服务。
  • 没有第三方分析 SDK（无 Firebase Analytics / Mixpanel / Amplitude / Sentry）。
  • 没有第三方崩溃收集 SDK。如您选择加入 Apple 系统级 MetricKit，Apple 会在提交给我们前做匿名聚合处理，我们无法识别到个人。
  • 没有广告 SDK。
  • 没有追踪 SDK。
  • 不读取您的通讯录、日历、健康数据、照片、位置或麦克风。

您的决策日记 —— 所有标题、事前推演、笔记、复盘、提炼的原则 —— 都不会离开您的设备，除非您主动开启 iCloud 同步或自己导出。

二、本地存储的内容

以下信息保存在应用沙盒的 CoreData 数据库中：

  • 您主动输入的决策标题、事前推演文本、心力评估分值
  • 您选择的领域标签（含 4 个预置标签及您自定义的标签）
  • 复盘时的评分、"是否会重来"选择、提炼的原则
  • 沉淀期内的过程笔记
  • 应用偏好（主题选择、通知设置、Onboarding 状态、Pro 购买状态）

三、iCloud 同步

若您在应用设置里主动开启 iCloud 同步，您的数据将在您自己的多台设备之间同步（iPhone / iPad / Mac），走 Apple 官方 CloudKit 私有数据库。

  • Apple 对 CloudKit 私有域数据实施端到端加密。
  • 开发者无权限查看、读取或访问您 CloudKit 中的数据。Apple 不给我们访问权限。
  • 若您登出 iCloud，或在应用内关闭 iCloud 同步，数据将不会离开您的设备。

四、导出功能

您可以随时把您的决策导出为 Markdown / JSON 或《我的原则》PDF 小册子（Pro 版）。

  • 导出的文件在您的设备本地生成。
  • 您决定把该文件发到哪里（AirDrop、Files、其它 App、邮件），我们不参与这个过程。

五、内购与支付

Pro 版是一次性买断的非订阅型内购（Non-Consumable），由 Apple StoreKit 2 处理。

  • Apple 处理全部支付流程与交易凭证。
  • 开发者从 Apple 只获知"该 Apple ID 是否购买过 Pro"这一事实，用于跨设备恢复购买。
  • 开发者不接收您的 Apple ID、支付卡信息或任何其他个人细节。

六、未来的 AI 能力（尚未上线）

Verdict v1.0 不含任何 AI 功能。若未来加入，将采用以下两种路径之一：

  • Apple Intelligence 本地模型：完全在您的设备本地运行，数据不离开设备。
  • BYOK（自带密钥）：您在应用设置里粘贴您自己的 API Key（Claude / OpenAI / Gemini）。调用 AI 时，您的数据从您的设备直接发送到您选择的 API 提供方。我们不作代理，不做日志，不做存储；也看不到您的 Key。

上述功能正式上线时，本隐私政策将同步更新。

七、权限使用说明

本应用可能请求以下系统权限：

  • 本地通知：用于在您设定的复盘日期发送到期提醒。通知在设备本地注册和触发，不涉及任何网络通信。
  • Siri / App Intents：让您可以说"记一个决定"或"记一笔今日回声"通过 Siri 快速唤起应用。所有交互由 Apple 系统处理，我们不接收原始语音或识别结果。

八、未成年人保护

本应用适龄评级 4+。我们不会主动收集任何年龄段用户的数据。由于本应用不联网也不采集，不存在向外部传输未成年人信息的可能性。

九、隐私政策变更

如本政策变更，我们会更新顶部的"最后更新"日期，并简要说明变更内容。由于我们不采集数据，未来的变更主要是措辞澄清，不会新增数据收集。
