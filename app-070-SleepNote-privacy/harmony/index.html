睡记 隐私政策

更新日期：2026-10-09 版本：1.0.0 适用应用：睡记（Bundle: com.xun.sleepnote） 开发者：SameX 联系邮箱：119123059@qq.com

---

本政策说明「睡记」如何处理你在使用本应用时产生的信息。我们的核心承诺很简单：本应用零传感器 / 零音频 / 零位置 / 零账户 / 零联网 / 零推送 / 零医疗结论；不收集、不上传、不共享任何用户数据，也不接入任何第三方 SDK。

---

一、我们处理的信息

本应用处理的全部信息都保存在你的本机 Preferences 中，仅供本应用自身读取：

  • 入睡时间戳（你本人按"点睡"大圆钮的那一刻）
  • 醒来时间戳（你本人按"点醒"大圆钮的那一刻）
  • 一夜的 1-5 星主观自评（你本人滑星选的那一下）
  • 一周起始日的本地偏好（周一 / 周日）
  • 隐私政策的首启同意状态

以上信息均由你本人在本应用内手动按钮录入，离开本机不存在任何副本。本应用不基于加速度、麦克风、心跳、位置或任何其它传感器推断你的睡眠；全部数据都是你自己手动按下按钮产生的。

二、我们不做的事（硬承诺）

本应用：

  • 零传感器：不读加速度、不读陀螺仪、不读任何体感数据
  • 零音频：不启用麦克风、不听呼噪、不录音
  • 零位置：不采集 GPS、不采集 WIFI / 基站定位
  • 零账户：不接入任何云端账号 / 第三方登录体系（不支持微信、华为、Apple 登录）
  • 零联网：不上传任何用户数据到服务器 —— 本应用无服务器组件
  • 零推送：不建立任何提示通道、不建系统闹钟、不震动
  • 零医疗结论：不显示任何"失眠 / 睡眠障碍 / 诊断 / 治疗 / 调理"字眼；星级为你本人主观自评、非医学评级、非算法推理；不给出任何作息指导
  • 不请求任何敏感系统权限：
  • 不请求相机权限
  • 不请求定位权限
  • 不请求麦克风权限
  • 不请求通讯录权限
  • 不请求通知权限
  • 不请求运动数据权限
  • 不接入任何第三方 SDK（无广告 SDK、无统计 SDK、无崩溃 SDK、无推送 SDK）
  • 不展示任何形式的广告
  • 不加任何连续天数 / 坚持徽章 / 对他人比较 / 排行等打卡焦虑叙事

三、数据存储与安全

  • 存储位置：鸿蒙系统 Preferences，位于本应用在系统分配的私有沙箱目录内
  • 存储格式：明文 JSON（你手动按钮产生的时间戳与星级不属于敏感个人信息，无加密必要）
  • 访问范围：仅本应用自身，其它应用无法访问
  • 卸载清理：卸载本应用时，系统会同步清除本应用的全部沙箱数据

四、数据导出与删除

  • 本应用 v1.0.0 不提供数据导出 / CSV 功能（规划在 v1.1 加入）
  • 如需清除全部数据，请在系统设置中卸载本应用；或在本应用内逐条删除一夜记录
  • 本应用无服务器端数据，无需额外的"远端删除"流程

五、未成年人保护

本应用不收集任何个人信息，因此也不单独针对未成年人进行信息收集。本应用面向所有用户开放使用。本应用不加打卡焦虑叙事、不加对他人比较、不加任何引导性作息指导，不构成对未成年人身心的额外压力。

六、政策变更

若本政策发生变更，新版本会随应用更新一起下发，更新日期会体现在本页顶部。重大变更会在首启再次弹出同意框。
