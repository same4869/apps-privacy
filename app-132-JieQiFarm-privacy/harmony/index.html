节气农事速查 隐私政策

生效日期：2026-10-11

1. 一句话总结

节气农事速查完全离线运行。它不联网、不发系统通知、不采集任何个人信息、不接任何第三方 API。所有节气数据和日期计算都在您的手机本地完成；您选择的"当选年份"存在本机 Prefs，卸载应用会清除。

2. 我们不收集什么

  • 不收集姓名 / 身份证 / 手机号 / 账号信息
  • 不收集定位 / 相册 / 相机 / 麦克风
  • 不收集设备 ID / IMEI / MAC
  • 不收集查询历史 / 使用行为日志
  • 不接任何第三方 SDK / 统计 / 推送 / 广告

3. 本机存了什么

应用在系统 Preferences 中保存两项:

  • 您选择的"当选年份"（例如:2026）
  • 是否已同意本隐私政策

不保存任何查询历史。卸载应用会清除所有本机数据。

4. 网络 / 通知 / 相机 权限

本应用不申请系统通知权限、不读取相机 / 相册 / 位置 / 麦克风,也不发任何业务网络请求;申请的网络权限（如有）仅用于鸿蒙系统基本运行要求。

5. 节气农事参考免责

  • 本应用仅为传统 24 节气参考,所列吃穿种钓建议源自民间俗语和地方农谚
  • 实际气候 / 农时 / 渔讯以当地农业气象部门发布为准
  • 不构成任何医疗 / 食疗 / 种植 / 垂钓方面的专业建议
  • 节气公历日期采用东经 120° 平均太阳黄经公式计算,1900-2099 年 ±1 天精度
  • 不涉及任何宗教 / 命理 / 占卜内容

6. 未成年人保护

本应用面向一般用户,不针对 14 岁以下未成年人,不采集任何可识别未成年人身份的信息。

7. 变更

隐私政策如有更新会随应用版本一并发布。使用本应用即视为同意最新版本。
