报销到期本 隐私政策

生效日期：2026-10-09

1. 我们收集什么

我们不收集任何可识别到您个人的信息。

报销到期本是一款本地的事件到期管理工具（本地日期倒计时工具）。您在应用内手动 录入的发票元数据 —— 金额（￥ 数值）、事由（文本）、开票日（日期）、公司报销期限 天数（整数）、已报销状态（标记）—— 全部由您主动输入，仅用于本机的"剩余天数" 倒计时展示与分组列表排序，不离开您的设备。

应用不读取您的通讯录、相册、位置、通话记录、短信、日历、系统设置、设备 ID、 IMEI、IDFA、OAID 或任何其他可识别到您个人的硬件 / 账号标识。

2. 数据存储

您在本应用内录入的发票元数据与"已报销"标记 100% 存储在您本机的应用沙盒 Preferences 中（key 前缀 biz_receiptdue_v1_），不离开您的设备、不上传到任何 服务器、不同步到任何云端账户。

卸载本应用会清空上述数据，恢复出厂设置也会清空上述数据。本应用不提供"账号找回 数据" / "重装恢复数据" 功能。

CSV 导出功能仅把您的发票元数据写入本应用沙盒的 Documents/receiptdue-exports/ 目录，产出的文件保留在您本机的应用沙盒内，不触发任何系统分享面板，不自动发送 到任何外部位置。您可以自行通过手机的文件管理工具把该文件搬运到您选择的位置 （本应用不参与此搬运过程）。

3. 第三方 SDK

本应用不集成任何第三方 SDK，包括但不限于：

  • 不集成任何统计 / 埋点 / 分析 SDK（友盟 / 神策 / GrowingIO / Firebase Analytics 等）
  • 不集成任何广告 SDK（穿山甲 / 优量汇 / 快手联盟 / AdMob 等）
  • 不集成任何推送 SDK（极光 / 个推 / 华为 Push Kit 等）
  • 不集成任何社交登录 / 分享 SDK（微信 / QQ / 微博 / ShareKit 等）
  • 不集成任何地图 / 定位 SDK（高德 / 百度地图 / 腾讯地图 / Location Kit 等）
  • 不集成任何图像识别 / OCR / AI 相关 SDK

应用仅依赖 HarmonyOS 系统提供的基础 UI 与存储 API（ArkUI / Preferences），不 依赖任何需要联网的鸿蒙 Kit。

4. 权限说明

本应用不申请任何敏感权限。

  • 不申请相机权限（无 OCR、无拍照识别、无发票影像采集）
  • 不申请相册 / 存储读写权限（无图片附件功能；CSV 导出写入的是应用沙盒内自有

Documents 目录，无需读写外部存储）

  • 不申请位置权限
  • 不申请麦克风权限
  • 不申请通知权限（本应用不发送任何推送、不弹本地提醒）
  • 不申请日历权限（公司报销期限天数是本应用内的本机倒计时常量，与您系统日历

无关联）

  • 不申请通讯录权限
  • 不申请电话 / 短信权限
  • 不申请设备信息权限
  • 不申请网络权限（应用全程无网，不发送任何网络请求）

5. 您的权利

  • 删除单条：进任一发票的详情页 → 右上角 edit → 底部"删除该条"→ 二次确认

后该发票从本机 Preferences 中永久移除。

  • 恢复为待报销：进已报销存档中任一条 → 详情页 → "恢复为待报销"→ 该条回

到待报销列表。

  • 清空全部：通过系统设置 → 应用管理 → 报销到期本 → 存储 → 清除数据，可

一次性清空本应用的全部数据。

  • 卸载应用：直接卸载本应用，所有本机数据随之清空，不留任何残留。
  • 导出备份：进我的区段 → "导出 CSV"→ 本应用会把您的全部发票元数据写入

应用沙盒的 Documents/receiptdue-exports/YYYY-MM.csv，您可以自行通过手机 文件管理工具搬运该文件到您选择的位置。

因本应用不收集您的任何可识别到个人的信息、不设账号体系、不上传任何数据，故 不涉及"查询个人数据副本 / 要求删除云端数据 / 账号注销"等场景 —— 您对本机数据 的完全控制即对您数据的完全控制。
