读书番茄钟 隐私政策

生效日期：2026-10-12

本政策说明「读书番茄钟」如何处理你的信息。请在使用前仔细阅读。本政策适用于本 app 的所有功能。

1. 我们收集什么

不收集。本 app 完全运行在你的设备上，不访问网络，不上传任何数据到服务器。本 app 没有服务器。

具体来说，以下信息都不会离开你的设备：

  • 你输入的书名
  • 每次阅读 session 的时长、页数、笔记
  • app 使用频次或任何埋点
  • 设备信息、位置信息、通讯录、相册

2. 本地存储了什么

为了让 app 工作，以下数据保存在你设备的本地存储（鸿蒙 preferences）中：

  • 你的阅读 session 列表（book_title / started_at / duration_min / pages_read / note）
  • 你的外观偏好（跟随系统 / 浅色 / 深色）
  • 你是否已同意本隐私政策

这些数据存储在你的设备上，不会上传到任何服务器。你可以随时在"我的 → 关于 → 清空所有数据"彻底清除。卸载 app 时所有数据会被系统自动清理。

3. 权限

本 app 不申请任何系统权限。无网络、无通知、无相机、无麦克风、无位置、无相册、无联系人、无短信、无电话。

4. 第三方 SDK

本 app 不接入任何第三方 SDK。无统计 SDK、无广告 SDK、无崩溃收集 SDK。

5. 未成年人

本 app 不针对未成年人设计，也不收集任何个人信息（含未成年人信息）。如果监护人发现未成年人使用本 app，可以随时让其卸载。

6. 内容与免责

  • app 内置的 8 本默认书名（百年孤独 / 小王子 / 活着 / 平凡的世界 / 三体 / 红楼梦 / 围城 / 人类简史）均为公开出版的经典名著名称，仅作用户输入时的建议标签，本 app 不提供这些书籍的内容、不涉及版权。
  • 本 app 不提供阅读建议或读后感生成，所有书名和笔记都是用户自己手输的本地标签。
  • 本 app 不构成任何教育建议或阅读指导，仅作时间与页数的记录工具。

7. 变更

如本政策有更新，会在下一次上架版本中更新"生效日期"。重大变更时会在 app 内"关于"页面有变更说明。
