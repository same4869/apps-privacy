柔习惯 隐私政策

生效日期：2026-10-08

柔习惯（下称"本应用"）是一款做给打卡疲劳者的本地习惯本。我们非常重视您的隐私，本政策说明我们不收集什么，以及您数据如何被保管。

1. 我们收集什么

我们不收集任何可识别到您个人的信息。本应用不请求您的姓名、手机号、邮箱、位置、通讯录、设备 ID、广告 ID、IMEI、IDFA、或任何同类标识符。

您在本应用内创建的所有内容（习惯、打卡记录、一句话笔记、外观设置等）均由您在本机输入，不离开您的手机。

2. 数据存储

您的所有数据 100% 存储在您本机的应用沙箱中（鸿蒙 preferences / 文件系统），不联网、不上传、不同步到任何云端。卸载本应用将同时清空全部数据，无任何残留。

3. 第三方 SDK

本应用不集成任何第三方 SDK。不含统计、分析、广告、推送、崩溃上报、A/B 测试、热更新、人脸识别、支付等任何第三方组件。

4. 权限说明

本应用不申请任何敏感权限。不请求定位、相机、麦克风、通讯录、日历、通知、读写外部存储等。应用正常运行所需的本地文件读写，全部限制在应用自身沙箱内，不触碰共享存储。

5. 您的权利

因为我们不存储您的任何数据到云端，所以不涉及"向他人索要数据"的流程。您可以：

  • 导出：在"我的 → 导出"中把全部记录导出为 JSON 文件；
  • 删除：卸载本应用即可清除全部本地数据；
  • 停用：直接停用或卸载本应用，不会留下任何残余。

本应用不涉及个人数据跨境传输、不涉及未成年人个人信息的收集。

6. 联系我们

如果您对本政策有任何疑问、建议、或投诉，欢迎联系：
