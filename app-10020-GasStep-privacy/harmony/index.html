一、我们是谁

燃气费预估（以下简称"本应用"）是一款完全离线的本地阶梯气价燃气费用预估小工具。本应用由开发者 ccflower713 独立开发，没有运营团队、没有服务器、没有后台。

二、我们收集什么

什么都不收集。 本应用在你手机上记录的所有信息（月份、立方米数、你写的感想），完完全全只在你手机本地保存。

  • 不采集设备 ID / IMEI / MAC / 广告 ID
  • 不采集地理位置
  • 不采集通讯录 / 短信 / 相册 / 相机 / 麦克风 / 传感器 / 蓝牙
  • 不采集浏览历史 / 使用时长 / 功能使用频次
  • 不采集任何形式的用户画像
  • 不接入任何第三方 SDK（无广告 SDK / 无统计 SDK / 无 Push SDK）

三、数据存储位置

你在本应用添加的所有立方米数和感想，都通过系统 preferences 接口写在你手机的本应用沙箱内。

  • 任何其他应用都读不到
  • 不同步到云、不同步到任何服务器、不同步到你的其他设备
  • 卸载本应用 = 所有数据自动清空
  • 应用内"关于 → 清空所有数据"按钮 = 立即清空所有记录

四、我们不做什么

  • 不联网：本应用不发起任何网络请求。
  • 不传感器：不读蓝牙、麦克风、加速度计。
  • 不通知：不发送任何本地通知。
  • 不账号：没有账号系统。
  • 不社交：你的立方米记录不会被分享、不会被公开。
  • 不广告：没有任何广告投放。
  • 不统计：没有用户行为统计。

五、权限说明

本应用在 module.json5 中声明的权限为空。装完就能用，不弹任何权限弹窗。

六、费用声明

本应用使用的阶梯气价阈值和单价是中国城镇居民阶梯气价（上海口径近似）默认值，仅供估算参考；不同省份不同用户的实际阶梯标准和单价可能不同，请以本地燃气公司公布的实际阶梯为准；本应用计算结果不构成任何缴费凭证。

七、你的权利

你随时可以：

  • 在"关于 → 清空所有数据"里一键清除本机所有记录
  • 卸载本应用，系统会连同沙箱一起删除
  • 通过邮箱 ccflower713@163.com 联系开发者询问任何隐私问题

八、第三方

本应用不集成任何第三方。

九、未成年人保护

本应用面向成年用户设计，由于不收集任何个人信息，未成年人使用亦不涉及隐私风险。

十、变更

本政策如有变更，将在应用内"隐私协议"页更新。重大变更会修改"生效日期"。
