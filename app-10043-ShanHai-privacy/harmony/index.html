山海奇观 隐私政策

欢迎使用「山海奇观」(以下简称"本应用")。本应用由 ccflower713 开发并运营。本隐私政策说明本应用如何处理您的个人信息。

生效日期: 2026-10-19

一、我们收集什么

本应用不收集任何您的个人信息。

  • 不收集姓名、电话、位置、设备 ID 等信息
  • 不读取通讯录、相册、文件、麦克风、相机
  • 不访问网络、不请求任何服务器
  • 不植入第三方 SDK

二、本地存储

本应用在手机本机 Preferences 保存:

  • 您标记"已识得"的神兽 id 列表
  • 应用偏好设置

卸载应用即永久删除,无云端备份。

三、权限需求

本应用不需要任何系统权限(无需网络 / 存储 / 相册 / 麦克风 / 位置)。

四、免责声明

本应用提供的《山海经》神兽图谱,仅为公共文化知识的科普展示。本应用:

  • 不作任何占卜 / 符咒 / 修仙 / 辟邪用途
  • 不作任何命理 / 运势 / 风水推演
  • 外形描述和出处引用公版典籍(《山海经》成书 ~2500 年前),翻译/演绎已标注
  • SVG 图示为简笔示意,不是神兽的权威考证形象
  • 若发现错误或建议新增神兽,欢迎邮件告知

五、政策变更

本政策如有变更,会在应用内更新版本号并提示您。
