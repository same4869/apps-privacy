纪要 隐私政策

更新日期：2026-10-09 版本：1.0.0 适用应用：纪要（Bundle: com.xun.meetminute） 开发者：纪要开发团队 联系邮箱：119123059@qq.com

---

本政策说明「纪要」如何处理你在使用本应用时产生的信息。我们的核心承诺很简单：本应用零音频 / 零相机 / 零 OCR / 零 AI / 零账户 / 零联网 / 零推送 / 零 Scheme 跳转；不收集、不上传、不共享任何用户数据，也不接入任何第三方 SDK。

---

一、我们处理的信息

本应用处理的全部信息都保存在你的本机 Preferences 中，仅供本应用自身读取：

  • 议题文本（你本人在议题字段输入的内容，最长 60 字）
  • 决策列表（你本人逐条输入的决策文本）
  • 行动项列表（你本人输入的事项 / 负责人 / 到期日三格）
  • 参会文本（你本人在参会字段输入的内容）
  • 备注文本（你本人在备注字段输入的内容）
  • 模板选择（你本人在顶部 Segment 选的"周会 / 评审 / 立项 / 一对一 / 空白"之一）
  • 列表决策条数小标签的显隐开关
  • Markdown 列表符号偏好（"-" 或 "*"）
  • 隐私政策的首启同意状态

以上信息均由你本人在本应用内手动输入或切换开关产生，离开本机不存在任何副本。本应用不基于录音、不基于语音识别、不基于图像识别、不基于任何 AI 分析来生成或修改以上信息；全部数据都是你自己手动敲入或点选产生的。

二、我们不做的事（硬承诺）

本应用：

  • 零音频：不启用麦克风、不录音、不做任何语音识别或语音转写
  • 零相机：不启用摄像头、不扫描、不做任何图像识别或 OCR
  • 零 AI：不接入任何 AI 大模型、不做任何自动总结 / 自动摘要 / 智能分析 / 润色建议
  • 零账户：不接入任何云端账号 / 第三方登录体系（不支持微信、华为、Apple、钉钉、飞书登录）
  • 零联网：不上传任何用户数据到服务器 —— 本应用无服务器组件、无云端存储
  • 零协作：不做多人实时协同编辑、不做评论 / @某人、不做模板市场 / 模板社区
  • 零推送：不建立任何提示通道、不建系统闹钟、不接 HMS Push、不震动
  • 零 Scheme 跳转：不跳转到任何外部 app（微信 / 企业微信 / 钉钉 / 飞书 / 系统日历 / 邮件）；导出 Markdown 仅通过系统剪贴板 API 实现
  • 零日历同步：行动项的"到期日"字段仅为视觉显示文本，不建系统日历事件、不同步任何第三方日历、不发送到期提示
  • 不请求任何敏感系统权限：
  • 不请求相机权限（CAMERA）
  • 不请求定位权限（LOCATION）
  • 不请求麦克风权限（MICROPHONE）
  • 不请求通讯录权限（CONTACTS）
  • 不请求日历权限（CALENDAR）
  • 不请求存储管理权限（STORAGE_MANAGE）
  • 不请求通知权限
  • 不请求运动数据权限
  • 不接入任何第三方 SDK（无广告 SDK、无统计 SDK、无崩溃 SDK、无推送 SDK、无 AI SDK）
  • 不展示任何形式的广告
  • 不收集任何可识别到个人身份的信息（无账号 ID / 无手机号 / 无邮箱 / 无 IDFA / 无 OAID / 无设备指纹）

三、剪贴板使用说明

本应用在用户主动点击「导出 Markdown」按钮时，调用鸿蒙系统 @ohos.pasteboard API 将当前纪要按模板拼接的 Markdown 文本写入系统剪贴板。此操作：

  • 仅在用户显式单击「导出 Markdown」按钮时触发，不自动写入
  • 仅写入文本，不写入任何图片、文件或敏感元数据
  • 写入内容完全由用户本人输入的 5 槽字段拼接而成，不含任何本应用添加的追踪信息
  • 系统剪贴板由操作系统管理，本应用不读取、不监听任何其它应用写入剪贴板的内容
  • 用户可随时清空系统剪贴板（通过系统输入法或剪贴板历史面板）

四、数据存储与安全

  • 存储位置：鸿蒙系统 Preferences，位于本应用在系统分配的私有沙箱目录内
  • 存储格式：明文 JSON（你手动输入的纪要文本不属于敏感个人信息，无加密必要）
  • 访问范围：仅本应用自身，其它应用无法访问
  • 卸载清理：卸载本应用时，系统会同步清除本应用的全部沙箱数据

五、数据导出与删除

  • 本应用提供"导出 Markdown 到剪贴板"功能（详见上文第三条）—— 用户可随时将任一条纪要导出为 Markdown 文本粘到任意位置
  • 本应用 v1.0.0 不提供批量导出 / CSV 功能（规划在 v1.1 加入）
  • 如需清除单条纪要，请在列表页长按卡片二次确认删除；或在详情页底部单击"删除此纪要"二次确认
  • 如需清除全部数据，请在系统设置中卸载本应用；本应用无服务器端数据，无需额外的"远端删除"流程

六、未成年人保护

本应用不收集任何个人信息，因此也不单独针对未成年人进行信息收集。本应用面向所有办公场景用户开放使用，内容由用户本人手动输入，不含任何对未成年人身心产生额外压力的打卡焦虑叙事或引导性评价。

七、政策变更

若本政策发生变更，新版本会随应用更新一起下发，更新日期会体现在本页顶部。重大变更会在首启再次弹出同意框。
