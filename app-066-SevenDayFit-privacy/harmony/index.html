七日练 隐私政策

生效日期：2026-10-09

1. 我们收集什么

我们不收集任何可识别到您个人的信息。七日练是一款纯本地的健身打卡工具，不要求您注册账号、不要求您填写姓名 / 手机 / 邮箱 / 生日 / 性别 / 身高 / 体重 / 职业等任何个人属性。

2. 数据存储

您在七日练中的全部数据 —— 项目库条目、每日勾选记录、本周 7 格状态、月视图柱状数据、streak 数值、外观偏好、每日提醒开关状态 —— 100% 保存在应用沙盒的 PrefsStore 中，不离开您的设备。

  • 存储位置：鸿蒙系统为本应用分配的沙盒目录
  • 存储形式：PrefsStore 键值对，key 统一以 biz_sevendayfit_v1_ 作为前缀
  • 典型 key：
  • biz_sevendayfit_v1_lib —— 项目库（您自建的项目名数组）
  • biz_sevendayfit_v1_day_YYYYMMDD —— 单日打卡记录
  • biz_sevendayfit_v1_appearance —— 外观偏好（Light / Dark / Auto）
  • biz_sevendayfit_v1_reminder_on —— 每日提醒开关状态
  • 卸载 app → 鸿蒙系统自动清除本应用沙盒的全部数据，无残留

本应用不联网、不上传、不同步任何数据到任何服务器 / 云端 / 第三方。

3. 第三方 SDK

本应用不集成任何第三方 SDK —— 没有广告 SDK、没有统计分析 SDK（无友盟 / 极光 / 神策 / 诸葛等）、没有推送 SDK（无 HMS Push / FCM）、没有登录 SDK、没有社交 SDK、没有图表 SDK、没有崩溃上报 SDK。

本应用仅使用鸿蒙系统提供的原生 API：PrefsStore（本地键值存储）、ArkTS Canvas（原生绘制）、reminderAgent（本地通知，仅当您主动开启"每日提醒"开关时才注册）。

4. 权限说明

本应用申请的敏感权限清单：

| 权限 | 鸿蒙权限名 | 用途 | 触发时机 | |---|---|---|---| | 本地通知 | ohos.permission.NOTIFICATION_CONTROLLER | 让系统在每天 20:00 弹一条本机提醒"今天练了吗" | 仅在您进入"我的" Tab → 每日提醒开关 → 首次打开时请求一次；您拒绝即不弹通知 |

本应用不申请以下任何敏感权限：

  • 不读取位置（无 LOCATION）
  • 不打开相机（无 CAMERA）
  • 不录音（无 MICROPHONE）
  • 不读取联系人（无 CONTACTS）
  • 不读写日历（无 CALENDAR）
  • 不读写外部存储（无 READ_MEDIA / WRITE_MEDIA）
  • 不读健康数据（无 HealthKit 类权限）
  • 不读运动传感器（无 ACTIVITY_MOTION / 加速度计 / 心率带 / 蓝牙秤）
  • 不联网（无 INTERNET）

5. 您的权利

您对本应用中的数据享有完全的本地控制权：

  • 查看：所有数据在应用内本周 Tab / 月视图 Tab / 项目库 Tab 可直接看到
  • 删除单条：进入"项目库" Tab 长按某条项目可删除该项目及其所有历史记录；进入"本周" Tab 的历史日格可清空该日打卡
  • 全部清空：卸载 app 即可清除全部数据
  • 停用提醒：进入"我的" Tab → 每日提醒开关可随时关闭本地通知

本应用不提供"账号注销"入口，因为本应用根本不存在账号。

6. 关于未成年人

本应用不针对 14 岁以下未成年人开发、不收集未成年人个人信息。本应用无内购、无广告、无 UGC 社区、无社交入口。

7. 政策变更

当本政策发生实质变更时，我们会在应用更新日志中显著告知。您继续使用本应用即视为接受变更后的政策。
