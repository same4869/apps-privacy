人情礼账本 隐私政策

生效日期：2026-10-10

人情礼账本（下称"本应用"）是一款完全本地运行的婚丧嫁娶份子钱台账工具。我们非常重视您的隐私，本政策说明我们不收集什么，以及您在本应用内的少量数据如何被保管。

1. 我们收集什么

我们不收集任何可识别到您个人的信息。本应用不请求您的姓名、手机号、邮箱、位置、通讯录、设备 ID、广告 ID、IMEI、IDFA 或任何同类标识符。

您在本应用内产生的全部数据——每一笔送出 / 收到的往来记录（人名、场合、金额、日期、备注）、按人聚合的汇总、未来场合提醒、外观设置（浅色 / 深色 / 跟随系统）——均由您在本机手动输入，不离开您的手机。

本应用中的"人名"由您自己填写（可用真名、昵称、代号或任意您方便识别的字符），应用本身不会去校验或关联任何通讯录 / 身份库 / 外部数据。

2. 数据存储

您的所有数据 100% 存储在您本机的应用沙箱中（鸿蒙 preferences 与应用私有 files 目录），不联网、不上传、不同步到任何云端。

本应用的数据总量极小，典型情况下不超过数十 KB，包含以下几组：

  • 往来记录：每一笔送出 / 收到的字段组合（人名、场合类型、金额、日期、备注）
  • 按人聚合：由往来记录派生的汇总视图数据
  • 未来场合：您主动添加的未来事件提醒（标题、日期、建议金额范围）
  • 外观设置：浅色 / 深色 / 跟随系统 三选一

卸载本应用将同时清空全部数据，无任何残留。您也可以在"我 → 使用说明"底部点"清空所有数据"，一次性清空本机所有本地记录。

3. 第三方 SDK

本应用不集成任何第三方 SDK。不含统计、分析、广告、推送、崩溃上报、A/B 测试、热更新、人脸识别、支付、金融 / 支付接口对接等任何第三方组件。

4. 权限说明

本应用不申请任何敏感权限。不请求定位、相机、麦克风、通讯录、日历、通知、读写外部存储、生物识别等。

您在"我 → 导出我的往来记录"中调起系统文件选择器把数据导出到外部位置时,是您本人的一次性选择，本应用不会在该操作外读写外部存储。

"下次回礼建议范围"说明：本应用对"按人聚合"视图下的"下次送礼建议范围"所做的任何数值提示，仅基于您自己过往手动输入的历史金额（均值 / 极值 ± 浮动）作为参考性估算，不构成任何理财、金融、支付、投资或习俗建议。本应用是本地台账工具，不提供金融服务。实际往来金额请根据您自身意愿与具体关系决定。

5. 您的权利

因为我们不存储您的任何数据到云端，所以不涉及"向他人索要数据"的流程。您可以：

  • 导出：在"我 → 导出我的往来记录"中把全部往来记录、按人聚合视图、未来场合清单和外观设置导出为 JSON 或纯文本文件；您可随时自行查阅、复制、迁移这些文件。
  • 删除：在"我 → 使用说明"底部点"清空所有数据"一次性清空本机所有本地记录；或直接卸载本应用。
  • 停用：直接停用或卸载本应用，不会留下任何残余。

本应用不涉及个人数据跨境传输、不涉及未成年人个人信息的收集。
