一小刻 隐私协议

版本：v1.0.0 生效日期：2026-10-10 适用应用：一小刻（PomoFlask） 开发者联系：119123059@qq.com

本协议说明一小刻这款应用会（和不会）如何处理你的数据。

一、我们收集什么

什么都不收集。 一小刻是一款 100% 本地单机应用。

  • 不收集账号信息（本应用没有账号功能）
  • 不收集设备标识符（IMEI / IDFA / OAID / MAC / UUID / 等）
  • 不收集位置信息
  • 不收集通讯录 / 日历 / 相册 / 短信 / 通话记录
  • 不收集任何系统传感器数据
  • 不收集任何埋点 / 行为 / 性能数据

二、我们如何处理你本地的训练记录

你的番茄钟设置、每日专注分钟与完成番茄数、终身累计统计，仅保存在你本机的 Preferences 存储中，仅本应用可访问。

  • 不上传到任何服务器
  • 不发送到任何第三方 SDK
  • 不写入系统共享区

你随时可以在"我"页面点"清空所有记录"抹除所有历史。卸载应用也会自动清空。

三、我们如何处理网络

本应用全程不联网。 没有初始化网络请求、没有后台拉取、没有埋点上传、没有 OTA 更新通道。应用启动后未请求任何系统网络权限。

四、我们不发通知

本应用不请求通知权限 / 不请求振动权限。番茄钟阶段结束的提示只在你打开应用时的屏幕上以动画形式呈现：

  • 不响铃、不震动、不弹系统通知
  • 若你需要番茄钟声音提示，请使用你的手机本机的其他闹钟应用

五、我们如何在后台计时

本应用不保活后台进程。你把应用切到后台时，计时器不作为后台服务存在；重新打开应用时，本应用会按"当前墙钟时间 - 阶段开始时间"推算当前应处的阶段（专注 / 休息）并刷新显示。

这意味着你退出应用期间不会消耗电量，也不会读取或上传任何数据。

六、第三方 SDK 清单

空。 本应用不集成任何第三方 SDK（含统计 / 推送 / 广告 / 支付 / 分享 / 社交登录等类别）。

七、未成年人

本应用是通用效率小工具，不含任何面向未成年或面向成年的特定内容，无年龄要求。

八、变更

若未来版本改变数据处理方式，会在应用更新说明中告知，并同步更新本协议版本号与生效日期。

九、联系我们

对本协议有任何疑问，请发邮件至 119123059@qq.com。
