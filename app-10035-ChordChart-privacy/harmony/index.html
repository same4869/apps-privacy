一、我们是谁

常见和弦表（以下简称"本应用"）是一款完全离线的本地吉他和弦速查手册。本应用由开发者 ccflower713 独立开发，没有运营团队、没有服务器、没有后台。

二、我们收集什么

什么都不收集。 本应用是纯静态知识速查：里面的 20 个常见和弦定义是编译期常量（公开乐理知识），没有用户记录字段、没有打卡功能、没有登录、没有搜索历史、没有收藏。

  • 不采集设备 ID / IMEI / MAC / 广告 ID
  • 不采集地理位置 / 定位信息
  • 不采集通讯录 / 短信 / 相册 / 相机 / 麦克风
  • 不采集浏览历史 / 使用时长 / 功能使用频次
  • 不采集任何形式的用户画像信息
  • 不接入任何第三方 SDK（无广告 SDK、无统计 SDK、无 Push SDK）

三、数据存储位置

本应用在你手机上只写入两个本地偏好字段：

  • privacy_agreed_v1：你是否已同意本隐私协议（布尔值）
  • appearance_mode_v1：你选的外观模式（整数：0 跟随系统 / 1 浅色 / 2 深色）

通过系统 preferences 接口写在你手机的本应用沙箱内（路径：应用私有空间 el2/base/preferences/）。

  • 任何其他应用都读不到
  • 不同步到云、不同步到任何服务器、不同步到你的其他设备
  • 卸载本应用 = 所有偏好自动清空

四、我们不做什么

  • 不联网：本应用不发起任何网络请求，不下载任何资源，不请求任何接口。
  • 不传感器：本应用不读取麦克风、加速度计、陀螺仪等传感器。
  • 不通知：本应用不发送任何本地通知，不响铃不震动。
  • 不账号：本应用没有账号系统，无需注册、无需登录。
  • 不社交：没有分享、没有排行、没有收藏、没有评论。
  • 不广告：没有任何广告投放。
  • 不统计：没有任何用户行为统计。
  • 不电商：本应用不是商城，不接入任何支付、链接、团购。
  • 不曲库：本应用不包含任何歌曲、乐谱、音频文件。

五、权限说明

本应用在 module.json5 中声明的权限为空。你装完就能用，不会弹任何权限弹窗。

六、你的权利

你随时可以：

  • 卸载本应用 —— 所有本地偏好立即清空
  • 在应用内切换外观模式 —— 浅/深/跟随系统三选一
  • 拒绝隐私协议 —— 本应用立即退出，不占用任何资源
