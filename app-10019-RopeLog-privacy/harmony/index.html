跳绳练习本 隐私政策

版本：1.0.0 生效日期：2026-10-13 开发者：ccflower713 联系邮箱：ccflower713@163.com

一、我们是谁

跳绳练习本（以下简称"本应用"）是一款完全离线的本地练习日志工具。本应用由开发者 ccflower713 独立开发，没有运营团队、没有服务器、没有后台。

本应用不涉及任何健康评估、训练建议或医疗提示。它只是你本地的一份文字记录本，所有次数 / 时长 / 感想都由你手动输入。

二、我们收集什么

什么都不收集。 本应用在你手机上记录的所有信息（每一笔的标签、动作模式、次数、时长、日期、感想、手感、标记），完完全全只在你手机本地保存。

  • 不采集设备 ID / IMEI / MAC / 广告 ID
  • 不采集地理位置 / 定位信息
  • 不采集通讯录 / 短信 / 相册 / 相机 / 麦克风
  • 不采集浏览历史 / 使用时长 / 功能使用频次
  • 不采集任何形式的用户画像信息
  • 不接入任何第三方 SDK（无广告 SDK、无统计 SDK、无 Push SDK）
  • 不读取运动传感器、心率、步数等健康数据

三、数据存储位置

你在本应用里添加的所有练习记录和感想，都通过系统 preferences 接口写在你手机的本应用沙箱内（路径：应用私有空间 el2/base/preferences/）。

  • 任何其他应用都读不到
  • 不同步到云、不同步到任何服务器、不同步到你的其他设备
  • 卸载本应用 = 所有数据自动清空
  • 应用内"我的 → 清空所有数据"按钮 = 立即清空所有记录和历史

四、我们不做什么

  • 不联网：本应用不发起任何网络请求，不下载任何资源。
  • 不传感器：本应用不读取麦克风、加速度计、陀螺仪、心率等传感器。
  • 不通知：本应用不发送任何本地通知，不响铃不震动，不提醒你去跳绳。
  • 不账号：本应用没有账号系统，无需注册、无需登录。
  • 不社交：你的练习记录不会被分享、不会被公开、不会出现在任何列表、排行榜、社区。
  • 不广告：没有任何广告投放。
  • 不统计：没有任何用户行为统计。
  • 不教练：本应用不给训练建议、不算卡路里、不估算运动量，所有数值由你手动填入。

五、权限说明

本应用在 module.json5 中声明的权限为空。你装完就能用，不会弹任何权限弹窗。

六、你的权利

你随时可以：

  • 在"我的 → 清空所有数据"里一键清除本机所有练习记录
  • 卸载本应用，系统会连同沙箱一起删除
  • 通过邮箱 ccflower713@163.com 联系开发者询问任何隐私问题

七、第三方

本应用不集成任何第三方。无广告 SDK、无统计 SDK、无崩溃上报 SDK、无 Push SDK、无登录 SDK。

八、未成年人保护

本应用面向成年用户设计，但由于不收集任何个人信息，未成年人使用亦不涉及隐私风险。

九、健康声明

本应用不是医疗产品、不是健身教练应用，不提供任何训练强度、安全建议或健康评估。使用过程中若感觉身体不适，请遵循你自己的判断，必要时咨询专业人士。本应用对任何由跳绳练习造成的身体影响不承担任何责任。

十、变更

本政策如有变更，将在应用内"隐私协议"页更新。重大变更会修改"生效日期"。
