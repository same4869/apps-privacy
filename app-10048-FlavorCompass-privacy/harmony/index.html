风味罗盘 隐私政策

欢迎使用「风味罗盘」(以下简称"本应用")。本应用由 ccflower713 开发并运营。本隐私政策说明本应用如何处理您的个人信息。

生效日期: 2026-10-27

一、我们收集什么

本应用不收集任何您的个人信息。

  • 不收集姓名、电话、位置、设备 ID 等信息
  • 不读取通讯录、相册、文件、麦克风、相机
  • 不访问网络、不请求任何服务器
  • 不植入第三方 SDK

二、本地存储

本应用在手机本机 Preferences 仅保存:

  • 用户首次启动的隐私协议同意状态
  • 用户收藏香料的 id 列表(不含任何用户输入文本)
  • 应用 QA 握手标记(内部使用,不含用户内容)

本应用不保存任何用户输入内容。筛选 / 查询在当前会话内存中处理,关闭即消失。

卸载应用即永久删除所有本地数据,无云端备份。

三、权限需求

本应用不需要任何系统权限(无需网络 / 存储 / 相册 / 麦克风 / 位置)。

四、免责声明

本应用提供的 80 种全球常见香料/调味料风味数据、搭配关系、产地分组,均为公共烹饪文化的教育性整理。本应用:

  • 是家庭烹饪的风味参考工具,不是米其林调味指南
  • 六维风味评分(甜/咸/酸/辣/苦/鲜)为编辑整理的大众口感认知参考,不作商业评级
  • 产地分组按地理区域组织,不涉及任何国家政治语言表述
  • 搭配建议来自公开菜谱文化,不包含品牌推荐或购买渠道

五、使用边界

  • 本应用不提供"食用某香料治某病"等健康功效声明
  • 具体烹饪用量请以菜谱为准,本应用仅做风味科普
  • 本应用不涉及食品安全/过敏源等专业医疗建议
  • 对过敏体质用户,建议使用新香料前咨询专业人士

六、变更与联系

本政策可能根据华为应用市场要求调整,更新日期以本文首部"生效日期"为准。
