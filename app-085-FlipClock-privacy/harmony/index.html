翻字钟 隐私协议

版本：v1.0.0 生效日期：2026-10-10 适用应用：翻字钟（FlipClock） 开发者联系：119123059@qq.com

本协议说明翻字钟这款应用会（和不会）如何处理你的数据。

一、我们收集什么

什么都不收集。 翻字钟是一款 100% 本地单机应用。

  • 不收集账号信息（本应用没有账号功能）
  • 不收集设备标识符（IMEI / IDFA / OAID / MAC / UUID / 等）
  • 不收集位置信息
  • 不收集通讯录 / 日历 / 相册 / 短信 / 通话记录
  • 不收集任何系统传感器数据
  • 不收集任何埋点 / 行为 / 性能数据

二、我们如何处理你本地的设置

你在应用内选择的主题、字号、深浅模式，仅保存在你本机的 Preferences 存储中，仅本应用可访问。

  • 不上传到任何服务器
  • 不发送到任何第三方 SDK
  • 不写入系统共享区
  • 卸载应用时，所有设置随之彻底删除

三、我们是否连接网络

不连接。 翻字钟应用启动到关闭的整个生命周期不发起任何网络请求。

  • 不接入任何统计 SDK（无友盟、无 Firebase、无华为 AGC Analytics）
  • 不接入任何广告 SDK
  • 不接入任何推送 SDK
  • 不接入任何崩溃上报 SDK
  • 不读取任何在线资源 / 远程配置
  • 不下载任何在线主题 / 字体 / 皮肤

四、不是闹钟 / 不发通知声明

本应用是视觉装饰钟，不是闹钟工具：

  • 不定闹铃 / 不发声
  • 不震动
  • 不弹系统通知
  • 不读写系统闹钟数据库
  • 不请求通知权限 / 不请求唤醒锁
  • 若你需要闹钟，请使用系统时钟或专门的闹钟应用

五、我们是否共享数据

不共享。 因为我们没有收集任何数据，也没有联网能力。

六、权限清单

翻字钟不申请以下任何权限：

  • 位置
  • 通讯录 / 短信 / 通话 / 日历
  • 相册 / 存储
  • 摄像头 / 麦克风
  • 蓝牙 / NFC
  • 读 / 写系统设置
  • 后台运行 / 自启动
  • 通知推送
  • 悬浮窗
  • 可访问性服务

应用唯一需要的是本地 Preferences 存储（鸿蒙系统默认授予，无需弹窗）。

七、未成年人保护

本应用无社交、无 UGC、无评论、无私聊、无广告、无诱导消费、无付费内容。全部功能本地完成，不涉及金钱与社交。

八、协议更新

如本协议有变更，新版本会随应用更新一起下发。你可以在"我 查看隐私协议"中查看当前版本。
