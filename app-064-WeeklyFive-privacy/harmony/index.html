周复盘打卡 隐私政策

生效日期:2026-10-09

1. 我们收集什么

我们不收集任何可识别到您个人的信息。您对本应用的所有使用行为——每周打分、填写一句话亮点与教训、查看 52 周反思地图、查看趋势折线、开关周日本地通知——都在您本机设备内完成,不会被记录、不会被上传。

本应用不要求也不支持注册 / 登录;不存在任何账号体系,不接入任何第三方 OAuth。

2. 数据存储

您在应用内创建的所有数据——每周 5 维度打分(成就 / 情绪 / 学习 / 关系 / 身体,各 1-5 分)、每周两句话(亮点 / 教训,各 1-50 字可留空)、本地偏好(外观 Light / Dark / Auto、周日通知开关)——仅存储在您本机设备的应用沙盒 PrefsStore 中,不会上传到任何服务器,不与任何第三方共享。

本应用无 CSV 导出、无云端备份、无跨设备同步。您所有的 52 周数据仅存在当前设备上。

卸载本应用将一并清除所有本地打分、两句话、偏好与通知注册。

3. 第三方 SDK

本应用不集成任何第三方 SDK:

  • 无广告 SDK
  • 无统计分析 SDK(无友盟 / 无 TalkingData / 无 Firebase Analytics)
  • 无崩溃上报 SDK
  • 无社交分享 SDK
  • 无远端推送 SDK(无 HMS Push / FCM / APNS)
  • 无地图 / 定位 SDK
  • 无支付 SDK
  • 无 NLP / 文本分析 SDK(您写的两句话仅本地存储,不做任何自动分析)

4. 权限说明

本应用仅在您主动开启"周日复盘通知"开关时才请求通知权限;其余任何敏感权限均不申请:

  • 通知权限 ohos.permission.NOTIFICATION_CONTROLLER:仅当您在"外观"页主动开启"周日复盘通知"开关时请求;用于每周日 21:30 弹一条本地通知"该做本周复盘了"。本通知走系统本地 reminderAgent API,不涉及任何服务器推送 / 云端下发。您可以在"外观"页随时关闭该开关,关闭后彻底不走 reminderAgent;也可在系统设置中撤销本应用的通知权限。
  • 不申请网络权限(本应用无联网能力)
  • 不申请位置权限
  • 不申请相机 / 麦克风权限
  • 不申请存储外部读写权限
  • 不申请日历读写权限
  • 不申请通讯录读写权限

5. 关于"情绪"维度与两句话输入

本应用的"情绪"维度仅是一个 1-5 分滑杆——您拖动滑杆给过去一周的情绪整体感受打个分,应用将该分数作为 5 维度之一存入 PrefsStore。本应用:

  • 不预制任何心理问卷 / 心理评估量表 / 心理测试
  • 不提供任何心理 / 情绪 / 医疗相关建议或指导
  • 不与任何医疗 / 心理咨询服务打通
  • 不对您输入的"亮点 / 教训"两句话做任何自动文本分析 / 情感分类 / 关键词提取
  • 不触发基于您心情内容的任何算法推荐或提醒

您的两句话仅作为"回看素材"存在应用沙盒,除非您主动打开 app 查看,不会被任何逻辑读取。

6. 关于周日本地通知

本应用的"周日复盘通知"是一个默认关闭的可选功能:

  • 默认 OFF,不主动骚扰您
  • 需要您在"外观"页主动开启,并授权系统通知权限
  • 开启后仅每周日 21:30 走系统本地 reminderAgent 弹一条通知
  • 通知内容固定为"周复盘打卡 · 该做本周复盘了 · 15 分钟 5 项分 2 句话",不含您任何个人数据
  • 本应用不走任何远端推送(无 HMS Push / FCM / APNS / 自建 WebSocket)
  • 您随时可在"外观"页关闭该开关,彻底清除所有已注册的本地通知

7. 您的权利

  • 查看:您对本应用的使用无需任何账号,所有数据都在当前年份的 52 瓦主屏与单周详情 overlay 中可见
  • 修改 / 删除:
  • 当周(本周)打卡可随时覆盖重打
  • 历史周打卡不可直接改写(避免篡改回忆),但可在"单周详情"overlay 中删除后再回填
  • 外观偏好 / 通知开关 / 隐私同意可随时调整
  • 彻底清除:卸载本应用将删除全部本地数据(52 周打分、所有两句话、偏好、通知注册),无服务器备份

8. 适用范围

本政策适用于本应用(鸿蒙单机版)全部功能。本应用无 Web 端、无其它平台版本、无云端服务。
