阶梯电费管家 隐私政策

生效日期：2026-10-09

1. 我们收集什么

我们不收集任何可识别到您个人的信息。

阶梯电费管家是一款本地的居民阶梯电费手算器（本地电费计算工具）。您在应用内 手动输入的月用电 kWh（数字）、选择的省份（固定枚举中的中文名）、每次点击 "计算"后由本机生成的"输入 + 结果"快照（时间戳 / 省份名 / kWh / ￥ 金额 / 三段阶梯 kWh 与小计）全部由您主动输入或点击触发产生，仅用于本机的"分段公式 计算"显示与"历史回看"排序，不离开您的设备。

应用不读取您的通讯录、相册、位置、通话记录、短信、日历、系统设置、设备 ID、 IMEI、IDFA、OAID、户号、电表号、运营商信息，或任何其他可识别到您个人的硬件 / 账号 / 公用事业账户标识。

2. 数据存储

您在本应用内输入的 kWh、选择的省份、历次计算快照 100% 存储在您本机的应用沙盒 Preferences 中（key 前缀 biz_tierpower_v1_），不离开您的设备、不上传到任何 服务器、不同步到任何云端账户。

31 省的阶梯分段 / 单价常量（居民阶梯电价政策参数）硬编码在应用的 ArkTS 常量 文件中，随应用安装包一次性落到您的设备；本应用不从任何服务器下载 / 更新 这些常量，所有阶梯政策数据随版本号发布固定。

卸载本应用会清空上述本地数据，恢复出厂设置也会清空上述数据。本应用不提供 "账号找回数据" / "重装恢复数据" 功能。

"复制结果到剪贴板"功能仅调用 HarmonyOS 系统的 pasteboard API 写入一段纯 文本（内容为您当前的计算输入与结果，由您主动触发），不触发系统分享面板， 不自动发送到任何外部位置。您可以自行把该文本粘贴到您选择的目的地（本应用 不参与此粘贴过程）。

3. 第三方 SDK

本应用不集成任何第三方 SDK，包括但不限于：

  • 不集成任何统计 / 埋点 / 分析 SDK（友盟 / 神策 / GrowingIO / Firebase Analytics 等）
  • 不集成任何广告 SDK（穿山甲 / 优量汇 / 快手联盟 / AdMob 等）
  • 不集成任何推送 SDK（极光 / 个推 / 华为 Push Kit 等）
  • 不集成任何社交登录 / 分享 SDK（微信 / QQ / 微博 / ShareKit 等）
  • 不集成任何地图 / 定位 SDK（高德 / 百度地图 / 腾讯地图 / Location Kit 等）
  • 不集成任何图像识别 / OCR / AI 相关 SDK
  • 不集成任何支付 / 收银 / 账单查询 SDK（支付宝 / 微信支付 / 国网 95598 / 支付

Kit 等）

应用仅依赖 HarmonyOS 系统提供的基础 UI 与存储 API（ArkUI / Preferences / Pasteboard），不依赖任何需要联网的鸿蒙 Kit。

4. 权限说明

本应用不申请任何敏感权限。

  • 不申请相机权限（无 OCR、无拍照识别、无电表照片采集）
  • 不申请相册 / 存储读写权限（无图片附件 / 无文件导入 / 无文件导出；复制结果仅

走剪贴板）

  • 不申请位置权限（省份由用户在应用内手动选择，与系统位置无关）
  • 不申请麦克风权限
  • 不申请通知权限（本应用不发送任何推送、不弹本地提醒 / 不发闹钟）
  • 不申请日历权限
  • 不申请通讯录权限
  • 不申请电话 / 短信权限（本应用不读 / 不查任何户号 / 不接收电力公司短信）
  • 不申请设备信息权限
  • 不申请网络权限（应用全程无网，不发送任何网络请求；31 省阶梯政策以 2024 年

公开发布版本随应用安装包一次性落到您的设备）

5. 您的权利

  • 删除单条历史：在"历史记录"区段长按任一条快照 → 选择"删除本条"→

该快照从本机 Preferences 中永久移除。

  • 清空全部历史：在"历史记录"区段右上角单击"清空"→ 二次确认后，所有

历史快照从本机 Preferences 中永久移除；您选择的省份与阶梯数据不受影响。

  • 切换省份：在"省份"行单击"切换 ›"→ 从 31 省列表中重选 → 新省份偏好

覆盖写入本机。

  • 复制结果：长按任一历史条 → "复制结果到剪贴板"→ 您可以把纯文本粘贴到

您选择的目的地（本应用不读 / 不写除剪贴板以外的任何位置）。

  • 清空全部数据：通过系统设置 → 应用管理 → 阶梯电费管家 → 存储 → 清除

数据，可一次性清空本应用的全部数据。

  • 卸载应用：直接卸载本应用，所有本机数据随之清空，不留任何残留。

因本应用不收集您的任何可识别到个人的信息、不设账号体系、不上传任何数据，故 不涉及"查询个人数据副本 / 要求删除云端数据 / 账号注销"等场景 —— 您对本机 数据的完全控制即对您数据的完全控制。
