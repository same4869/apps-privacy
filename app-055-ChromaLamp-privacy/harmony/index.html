流光屏 隐私政策

生效日期：2026-10-08

流光屏（下称"本应用"）是一款完全本地运行的屏幕色灯 / 色卡 / 应急手电 / 色盲自测工具。我们非常重视您的隐私，本政策说明我们不收集什么，以及您在本应用内的少量设置如何被保管。

1. 我们收集什么

我们不收集任何可识别到您个人的信息。本应用不请求您的姓名、手机号、邮箱、位置、通讯录、设备 ID、广告 ID、IMEI、IDFA 或任何同类标识符。

您在本应用内产生的全部数据——收藏色列表、最近使用色列表、外观设置（浅色 / 深色 / 跟随系统）——均由您在本机输入，不离开您的手机。

2. 数据存储

您的所有数据 100% 存储在您本机的应用沙箱中（鸿蒙 preferences），不联网、不上传、不同步到任何云端。

本应用的数据总量极小，典型情况下不超过数 KB，包含以下三组：

  • 收藏色：您主动"心一下"保存的 HEX 颜色列表
  • 最近使用色：您切换过的颜色自动记录的 HEX 列表，长度上限 20 条，先进先出
  • 外观设置：浅色 / 深色 / 跟随系统 三选一

卸载本应用将同时清空全部数据，无任何残留。

3. 第三方 SDK

本应用不集成任何第三方 SDK。不含统计、分析、广告、推送、崩溃上报、A/B 测试、热更新、人脸识别、支付等任何第三方组件。

4. 权限说明

本应用不申请任何敏感权限。不请求定位、相机、麦克风、通讯录、日历、通知、读写外部存储、闪光灯、系统亮度调节等。

应用将屏幕铺满某种颜色的能力，由界面绘制（ArkUI Canvas）直接实现，并不调用系统闪光灯或相机。应急手电功能是用全屏白色来提供照明，而不是打开系统闪光灯；您可以通过手机自带的下拉状态栏手动把屏幕亮度调到最大以获得更好的照明效果。

您在"我的 → 导出我的色数据"中调起系统文件选择器把色数据导出到外部位置时，是您本人的一次性选择，本应用不会在该操作外读写外部存储。

色盲自测功能说明：本应用的"色盲自测色环"仅为色觉参考工具，不构成任何医疗诊断、治疗建议或临床结论。如您对自己的色觉有疑虑，请咨询专业医疗机构。本应用不属于医疗产品，所提供的内容仅为您个人视觉参考。

5. 您的权利

因为我们不存储您的任何数据到云端，所以不涉及"向他人索要数据"的流程。您可以：

  • 导出：在"我的 → 导出我的色数据"中把收藏色、最近用色和外观设置导出为 JSON 或纯文本文件；您可随时自行查阅、复制、迁移这些文件。
  • 删除：在"我的 → 收藏色"中长按色点可单条删除；在"我的 → 使用说明"底部可"清空最近用色记录"；或直接卸载本应用，一次清除全部本地数据。
  • 停用：直接停用或卸载本应用，不会留下任何残余。

本应用不涉及个人数据跨境传输、不涉及未成年人个人信息的收集。
