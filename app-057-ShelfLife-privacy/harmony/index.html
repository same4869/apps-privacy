临期雷达 隐私政策

生效日期：2026 年 10 月 9 日 版本：1.0.0

感谢您使用"临期雷达"。本应用由"临期雷达开发团队"开发并维护。我们严肃对待您的隐私，承诺按本政策向您说明本应用的全部数据处理方式。

1. 核心承诺（一句话总结）

本应用全程本地运行，不联网、不登录、不收集、不上传、不同步您的任何个人信息。

卸载应用等同于永久删除您的所有数据，我们没有任何方式对您的数据进行恢复、备份或访问。

2. 本应用会处理哪些数据？

本应用仅在您本机的应用沙盒内处理以下数据，均不会离开您的设备：

2.1 您主动输入的物品档案信息

  • 物品名字（例如"生抽 海天味极鲜"）
  • 物品类目（调味品 / 药品 / 护肤品 / 食品）
  • 购入日期、保质期天数、开封日期、开封后保质期月数
  • 存放位置、备注

2.3 您的应用偏好设置

  • 外观主题（Light / Dark / Auto）
  • 临期通知设置（开启状态、每日提醒时间、临期阈值天数）
  • 列表筛选 / 排序态

3. 本应用不会收集什么？

本应用不会以任何方式收集、使用或传输以下信息：

  • 您的姓名、身份证号、手机号、邮箱、位置信息、设备 ID / IMEI / IDFA / OAID
  • 您的通讯录、短信、通话记录、浏览历史
  • 任何用于广告投放或行为分析的数据
  • 您在应用内的点击、停留时长、使用习惯
  • 您的健康、医疗、金融信息（本应用的"药品"分类仅为物品档案登记，不收集任何用药行为、剂量、处方、就诊记录等医疗相关信息）

4. 权限说明

本应用申请以下权限，且仅在您主动触发对应操作时使用：

4.2 ohos.permission.NOTIFICATION_CONTROLLER（通知权限）

  • 用途：仅用于在您开启"临期通知"后，推送本地通知"XX 还有 N 天就要过期"
  • 范围：100% 本地触发，不涉及任何服务器推送通道
  • 拒绝后果：您将无法收到临期提醒；物品档案和列表色签紧迫度分级仍正常可用

5. 数据存储与安全

  • 存储位置：本应用所有数据保存在您设备的应用沙盒内（HarmonyOS 系统为每个应用隔离的私有目录），其他应用无法访问
  • 存储机制：使用 HarmonyOS 系统 Preferences / 沙盒文件系统 API
  • 传输：本应用不进行任何网络传输。无服务器、无云同步、无 API 调用
  • 卸载：卸载应用后，HarmonyOS 系统将自动清除本应用的所有本地数据，不可恢复

6. 第三方 SDK 清单

本应用不集成任何第三方 SDK。

  • 不集成分析 SDK（无友盟、神策、GA）
  • 不集成广告 SDK（无穿山甲、腾讯广告、Google AdMob）
  • 不集成推送 SDK（通知完全本地）
  • 不集成社交分享 SDK
  • 不集成支付 SDK（本应用不提供任何付费功能）

7. 关于 "药品" 分类的特别声明

本应用的"药品"分类仅为物品属性档案登记，用于记录您家中药品的保质期和到期倒数。

本应用不提供以下任何服务，所有相关内容以您实际商品包装、医生指导、药品说明书为准：

  • 用药建议、用药指导、剂量推荐
  • 疗效说明、对症建议、处方指引
  • 医疗诊断、治疗方案、健康咨询
  • 药品品质评价、安全性评价

如您有用药或健康问题，请咨询执业医师或药师。

8. 关于"食品 / 调味品"分类的特别声明

本应用的"食品"和"调味品"分类仅为物品档案登记，用于您自行管理家中食品的保质期。

所有食品是否安全食用，请以商品包装标注、国家食品安全标准、您的实际观察为准。 本应用显示的"剩余天数"仅是基于您输入的保质期的自动计算结果，不构成食品安全建议。

9. 未成年人保护

本应用不针对未成年人设计。本应用不收集任何可识别未成年人身份的信息。

10. 政策的变更

如本政策发生变更，我们将在应用内更新本文件，并更新顶部的"生效日期"。继续使用本应用即表示您接受更新后的政策。
