睡眠质量本 隐私政策

版本：1.0.0 生效日期：2026-10-13 开发者：ccflower713 联系邮箱：ccflower713@163.com

一、我们是谁

睡眠质量本（以下简称"本应用"）是一款完全离线的本地主观感受手输日记工具。本应用由开发者 ccflower713 独立开发，没有运营团队、没有服务器、没有后台。

本应用仅做本地主观感受记录，不提供任何医疗诊断、健康评估、睡眠建议或数据解读。

二、我们收集什么

什么都不收集。 本应用在你手机上记录的所有信息（每一笔的日期、1-5 星感觉值、你写的一句话），完完全全只在你手机本地保存。

  • 不采集设备 ID / IMEI / MAC / 广告 ID
  • 不采集地理位置 / 定位信息
  • 不采集通讯录 / 短信 / 相册 / 相机 / 麦克风 / 加速度传感器
  • 不采集浏览历史 / 使用时长 / 功能使用频次
  • 不采集任何形式的用户画像信息
  • 不接入任何第三方 SDK（无广告 SDK、无统计 SDK、无 Push SDK）

三、数据存储位置

你在本应用里添加的所有感觉记录和一句话，都通过系统 preferences 接口写在你手机的本应用沙箱内（路径：应用私有空间 el2/base/preferences/）。

  • 任何其他应用都读不到
  • 不同步到云、不同步到任何服务器、不同步到你的其他设备
  • 卸载本应用 = 所有数据自动清空
  • 应用内"关于 → 清空所有数据"按钮 = 立即清空所有记录和历史

四、我们不做什么

  • 不联网：本应用不发起任何网络请求，不下载任何资源。
  • 不传感器：本应用不读取麦克风、加速度计、陀螺仪等传感器。
  • 不通知：本应用不发送任何本地通知，不响铃不震动。
  • 不账号：本应用没有账号系统，无需注册、无需登录。
  • 不社交：你的记录不会被分享、不会被公开、不会出现在任何列表、排行榜、社区。
  • 不广告：没有任何广告投放。
  • 不统计：没有任何用户行为统计。
  • 不做医疗诊断、健康评估、睡眠建议或数据解读：1-5 星只是你自己的主观感觉标签，本应用不下任何结论、不输出任何建议、不做任何解读。

五、权限说明

本应用在 module.json5 中声明的权限为空。你装完就能用，不会弹任何权限弹窗。

六、你的权利

你随时可以：

  • 在"关于 → 清空所有数据"里一键清除本机所有感觉记录
  • 卸载本应用，系统会连同沙箱一起删除
  • 通过邮箱 ccflower713@163.com 联系开发者询问任何隐私问题

七、第三方

本应用不集成任何第三方。无广告 SDK、无统计 SDK、无崩溃上报 SDK、无 Push SDK、无登录 SDK。

八、未成年人保护

本应用面向成年用户设计，但由于不收集任何个人信息，未成年人使用亦不涉及隐私风险。

九、变更

本政策如有变更，将在应用内"隐私协议"页更新。重大变更会修改"生效日期"。
