常见问题

为什么只支持山东省？

V1 首发版专注做透山东省数据（一分一段表 + 招生录取结果 + 双一流名单）。其它省份的数据格式和高考规则差异较大，将在后续版本陆续上线。想优先支持某个省份？欢迎邮件告诉我们。

数据是最新的吗？

目前包含山东省 2023、2024、2025、2026 四届数据。每年高考录取结束后（一般 8-9 月）会通过版本更新同步当年数据。

付费后换手机数据能恢复吗？

付费权益跟随 Apple ID：同一个 Apple ID 登录到新手机，进入 研报 tab → 解锁 PRO → 右上角"恢复" 即可恢复已购权益。至于模考数据、心愿单等本地数据，需要提前使用 我的 → 数据备份 → 导出全部数据 保存 JSON 备份，然后在新手机上导入恢复。

学生解锁和家庭解锁怎么选？

如果只需要学生自己看陪跑数据 + 学生手记，¥68 学生解锁就够。如果家长也需要看家长决策手册（含独家 5 页家长视角：投资回报比、断档预警、专业冷热、亲子共读、客观分析），推荐 ¥168 家庭解锁。家庭解锁开启了苹果家庭共享，家庭内一个 Apple ID 购买后其它成员可免费使用。

已经买了学生解锁想升级到家庭解锁怎么办？

目前苹果 IAP 不支持"补差价升级"，你需要在付费墙里选择家庭解锁并支付 ¥168 全额。学生解锁不会因此失效，你可以联系我们通过 Apple App Store 退款渠道申请退回学生解锁的 ¥68。

报告生成后数据能保存多久？

永久保存。已生成的学生手记 / 家长决策手册都会以 JSON 快照 + PDF 归档到你设备的本地存储中，只要不清空 App 数据、不卸载 App，就一直能查看。

App 有 bug 或数据不准怎么办？

发邮件告诉我们，附上：iOS 系统版本、App 版本号（我的 tab → 关于 → 版本）、遇到问题的截图或详细复现步骤。我们会在下一个版本修复。

能否申请退款？

所有付费通过苹果 App Store 处理，你可以在 reportaproblem.apple.com 申请退款。苹果的退款政策独立于我们，我们无法直接为你退款。但如遇服务不可用或内容明显有误，我们可协助你和苹果沟通。

如何加入外省 waitlist？

目前请发邮件到 same4869@163.com，写上"外省 waitlist"和你的省份，我们会在你所在省份上线时通知你。V2 版本会在 App 内加正式的 waitlist 入口。
