算日距 隐私政策

更新日期：2026-10-09 版本：1.0.0 适用应用：算日距（Bundle: com.xun.datespan） 开发者：算日距开发团队 联系邮箱：119123059@qq.com

---

本政策说明「算日距」如何处理你在使用本应用时产生的信息。我们的核心承诺很简单：本应用零相机 / 零 OCR / 零 AI / 零定位 / 零账户 / 零联网 / 零推送 / 零 Scheme 跳转；不收集、不上传、不共享任何用户数据，也不接入任何第三方 SDK。

---

一、我们处理的信息

本应用处理的全部信息都保存在你的本机 Preferences 中，仅供本应用自身读取：

  • 起始日期（你本人在 DatePicker 中点选的年月日）
  • 终止日期（你本人在 DatePicker 中点选的年月日）
  • 计算历史记录（你本人在主页点击「存到历史」后保存的两日 + 结果快照）
  • 隐私政策的首启同意状态

以上信息均由你本人在本应用内手动点选或点击产生，离开本机不存在任何副本。本应用不基于相机、不基于图像识别、不基于定位、不基于任何 AI 分析来生成或修改以上信息；全部数据都是你自己手动点选产生的。

二、我们不做的事（硬承诺）

本应用：

  • 零相机：不启用摄像头、不扫描、不做任何图像识别或 OCR
  • 零 OCR：不做任何文字识别或条码识别
  • 零 AI：不接入任何 AI 大模型、不做任何自动分析 / 自动推荐 / 智能换算
  • 零账户：不接入任何云端账号 / 第三方登录体系（不支持微信、华为、Apple、钉钉、飞书登录）
  • 零联网：不上传任何用户数据到服务器 —— 本应用无服务器组件、无云端存储
  • 零社区：不做日距圈 / 晒天数 / 评论 / @某人 / 分享墙任何形式
  • 零电商：不接入任何购物商城 / 下单 / 支付 / 推广链接
  • 零推送：不建立任何提示通道、不建系统闹钟、不接 HMS Push、不震动、不发声
  • 零 Scheme 跳转：不跳转到任何外部 app（微信 / 系统日历 / 邮件）；复制功能仅通过系统剪贴板 API 实现
  • 零日历读取：不读取、不写入、不订阅任何系统日历或第三方日历数据；两日期完全由用户手动在 DatePicker 中点选
  • 零定位：不请求任何位置权限、不基于地理位置做任何推荐
  • 不请求任何敏感系统权限：
  • 不请求相机权限（CAMERA）
  • 不请求定位权限（LOCATION）
  • 不请求麦克风权限（MICROPHONE）
  • 不请求通讯录权限（CONTACTS）
  • 不请求日历权限（CALENDAR）
  • 不请求存储管理权限（STORAGE_MANAGE）
  • 不请求通知权限
  • 不请求运动数据权限
  • 不接入任何第三方 SDK（无广告 SDK、无统计 SDK、无崩溃 SDK、无推送 SDK、无 AI SDK）
  • 不展示任何形式的广告
  • 不收集任何可识别到个人身份的信息（无账号 ID / 无手机号 / 无邮箱 / 无 IDFA / 无 OAID / 无设备指纹）

三、剪贴板使用说明

本应用在用户主动点击「复制结果」按钮时，调用鸿蒙系统 @ohos.pasteboard API 将当前的计算结果（6 槽文本：天 / 小时 / 分钟 / 秒 / 周（含余） / 月（含天））拼成多行字符串写入系统剪贴板。此操作：

  • 仅在用户显式单击「复制结果」时触发，不自动写入
  • 仅写入文本，不写入任何图片、文件或敏感元数据
  • 写入内容完全由用户点选的两个日期和本应用的纯函数式计算结果组成，不含任何本应用添加的追踪信息
  • 系统剪贴板由操作系统管理，本应用不读取、不监听任何其它应用写入剪贴板的内容
  • 用户可随时清空系统剪贴板（通过系统输入法或剪贴板历史面板）

四、数据存储与安全

  • 存储位置：鸿蒙系统 Preferences，位于本应用在系统分配的私有沙箱目录内
  • 存储格式：明文 JSON（你手动点选的日期和计算结果不属于敏感个人信息，无加密必要）
  • 访问范围：仅本应用自身，其它应用无法访问
  • 卸载清理：卸载本应用时，系统会同步清除本应用的全部沙箱数据

五、数据删除

  • 单条历史记录：在主页"最近计算"列表长按某行 → 弹"删除此记录？"确认 → 删
  • 全部历史：路由到"关于"页 → 点"清空历史" → 二次确认 → 清空
  • 全部应用数据：在系统设置中卸载本应用；本应用无服务器端数据，无需额外的"远端删除"流程

六、未成年人保护

本应用不收集任何个人信息，因此也不单独针对未成年人进行信息收集。本应用面向所有需要计算两日之间间隔的场景（工作提醒 / 考试倒数 / 纪念日回顾 等）开放使用，内容由用户本人手动点选产生，不含任何对未成年人身心产生额外压力的打卡焦虑叙事。

七、政策变更

若本政策发生变更，新版本会随应用更新一起下发，更新日期会体现在本页顶部。重大变更会在首启再次弹出同意框。
