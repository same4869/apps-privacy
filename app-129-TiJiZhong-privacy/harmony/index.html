体积重 隐私政策

生效日期：2026-10-10

1. 一句话总结

体积重完全离线运行。它不联网、不采集任何个人信息、不接入任何账号或物流 API。你输入的所有运单数据只存在你自己的手机上。

2. 我们不收集什么

  • 不收集姓名 / 身份证 / 手机号 / 账号信息
  • 不收集定位信息
  • 不收集通讯录 / 相册 / 相机 / 麦克风
  • 不收集设备 ID / IMEI / MAC
  • 不收集浏览历史 / 使用行为日志
  • 不接任何第三方 SDK / 统计 / 推送 / 广告

3. 本机存了什么

你新建的运单数据（名字、长宽高、实重、divisor、备注、保存时间）以及默认 divisor 设置，通过系统 Preferences 存在本机沙盒。卸载应用会清除所有本机数据。

4. 网络权限

本应用申请的网络权限（如有）仅用于鸿蒙系统基本运行要求，不发起任何业务请求。

5. 核算结果免责

  • 本应用结果仅为自助核算参考，不代表任何承运商 / 快递 / 货代的真实计费重
  • 实际计费以承运商开单为准（不同承运商 divisor / 换算规则各异）
  • 本应用不作任何商家询价 / 关税测算 / 合同报价依据

6. 未成年人保护

本应用面向一般用户，不针对 14 岁以下未成年人，不采集任何可识别未成年人身份的信息。

7. 变更

隐私政策如有更新会随应用版本一并发布。使用本应用即视为同意最新版本。
