化妆品效期 隐私协议

生效日期：2026-10-13

欢迎使用化妆品效期（以下简称"本应用"）。本应用由开发者 李月翠 发布（AGC 账号署名 ccflower713），联系邮箱 ccflower713@163.com。请仔细阅读本协议后再使用本应用。

一、我们不收集任何个人信息

本应用完全不收集任何可识别到你本人的信息。我们不要求你注册账号，不读取你的手机号、设备 ID、位置、相册、通讯录、麦克风、相机、生物特征或任何其他个人数据。

你在本应用内手工输入的化妆品名称 / 开封日期 / 选择的效期档均仅在本机应用沙箱 preferences 内保存，不上传到任何服务器，不与任何第三方共享，不以任何形式对外展示。

二、我们不联网、不同步、不推送

本应用完全离线运行，不发起任何网络请求，不包含统计 SDK / 广告 SDK / 推送 SDK / 分析 SDK，不接入任何第三方云服务。你的全部化妆品记录仅存在于你当前这台设备上。

三、我们不社交、不 UGC、不 AIGC

本应用不含用户之间的任何互动（评论 / 关注 / 分享 / 排行 / 聊天）。你输入的化妆品名称只给你自己看。效期档只有本地固定四常量（6 个月 / 12 个月 / 18 个月 / 24 个月），不接任何大模型 API，不下载，不随版本动态下发。

四、我们不碰危险权限

本应用不申请任何系统权限，无需定位 / 相机 / 麦克风 / 存储 / 通讯录 / 日历 / 相册 / 蓝牙 / 蜂窝数据等任何权限。

五、数据存储与删除

你的化妆品数据存储在你设备的本应用沙箱 preferences 内。可通过以下方式删除：

  • 在"我的 → 关于 → 清空所有数据" 一键清空
  • 卸载本应用会自动清除沙箱内全部数据

六、未成年人保护

本应用不针对未成年人提供服务，不包含任何面向未成年人的广告或诱导内容。

七、协议变更

未来版本如调整数据处理方式，我们会在本页更新"生效日期"并在应用内通知。继续使用本应用视为接受更新后的协议。
