一、我们是谁

中国省份本（以下简称"本应用"）是一款完全离线的三十四省级行政区速查工具。本应用由开发者 ccflower713 独立开发，没有运营团队、没有服务器、没有后台、没有大模型 API 接入。

二、我们收集什么

什么都不收集。 本应用展示的三十四条省份数据（省名 / 简称 / 车牌字母 / 省会 / 面积 / 人口 / 一行地理特色）均为应用代码里的编译期常量，不是在线下载的。你在本应用里的所有操作（切换筛选 / 打开详情 / 切外观）完完全全只在你手机本地处理，不发往任何服务器。

  • 不采集设备 ID / IMEI / MAC / 广告 ID
  • 不采集地理位置 / 定位信息
  • 不采集通讯录 / 短信 / 相册 / 相机 / 麦克风 / 加速度传感器
  • 不采集浏览历史 / 使用时长 / 功能使用频次
  • 不采集任何形式的用户画像信息
  • 不接入任何第三方 SDK（无广告 SDK、无统计 SDK、无 Push SDK、无 AI/LLM SDK）
  • 三十四条省份数据和特色描述均为出厂固定本地字符串常量，不随版本动态下发、不走任何在线接口

三、数据存储位置

本应用仅在本地保存一个"外观模式"偏好（跟随系统 / 浅色 / 深色），通过系统 preferences 接口写在你手机的本应用沙箱内（路径：应用私有空间 el2/base/preferences/）。

  • 任何其他应用都读不到
  • 不同步到云、不同步到任何服务器、不同步到你的其他设备
  • 卸载本应用 = 该偏好自动清空

四、权限

本应用不申请任何系统权限：无网络权限 / 无相机 / 无麦克风 / 无定位 / 无存储 / 无通讯录 / 无通知。

五、你的权利

  • 自由停止使用：卸载本应用即可，所有本地偏好随卸载清空。
  • 投诉与反馈：可发邮件至 ccflower713@163.com 反馈建议；若涉及隐私问题，开发者会在十五个工作日内回复。

六、未成年人

本应用不特别面向未成年人收集任何信息（我们本来就什么都不收集）。

七、政策变更

隐私政策若有变更，会在本应用的新版本内更新；重要变更会通过首启重新弹隐私协议方式告知用户。

八、关于内容

  • 省份数据和一行地理特色描述力求客观中性，仅引用自然资源部公开资料和第七次全国人口普查公报（2020）
  • 如发现数据与官方公开资料存在不一致，欢迎发邮件至 ccflower713@163.com 反馈，开发者会在下一版本修订
  • 本应用不表达任何政治、宗教、民族、地域评价立场
