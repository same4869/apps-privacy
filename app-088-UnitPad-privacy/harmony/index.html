量译台 隐私协议

版本：v1.0.0 生效日期：2026-10-10 适用应用：量译台（UnitPad） 开发者联系：119123059@qq.com

本协议说明量译台这款应用会（和不会）如何处理你的数据。

一、我们收集什么

什么都不收集。 量译台是一款 100% 本地单机应用。

  • 不收集账号信息（本应用没有账号功能）
  • 不收集设备标识符
  • 不收集位置信息
  • 不收集通讯录 / 日历 / 相册 / 短信 / 通话记录
  • 不收集任何系统传感器数据
  • 不收集任何埋点 / 行为 / 性能数据
  • 不收集你输入的待换算数值（输入值连同输出一起在你退出当前类别时丢弃）

二、我们如何处理你的 UI 偏好

你最后选的类别 Tab + 每类的主单位，仅保存在你本机的 Preferences 存储中。这些偏好不包含任何数值输入内容。

  • 不上传到任何服务器
  • 不发送到任何第三方 SDK
  • 卸载应用自动清空

三、我们如何处理网络

本应用全程不联网。 没有汇率获取、没有服务端换算、没有埋点上传。应用启动后未请求任何系统网络权限。

四、BMI 与医疗声明

量译台的 BMI 页面只做"身高 + 体重 → BMI"的算术演算，并按经典 WHO 分段显示文字标签（偏瘦 / 正常 / 超重 / 肥胖）。本应用：

  • 不构成医疗建议 / 诊断 / 处方 / 治疗依据
  • 不收集 / 不上传任何身体数据
  • 不与任何医疗 / 保险机构有数据交换

如你有健康顾虑，请咨询执业医生，不要以本应用结果作为决策依据。

五、第三方 SDK 清单

空。 本应用不集成任何第三方 SDK。

六、未成年人

本应用是通用效率小工具，不含任何敏感内容。

七、变更

若未来版本改变数据处理方式，会在应用更新说明中告知。
