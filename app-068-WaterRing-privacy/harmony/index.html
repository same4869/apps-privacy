饮水环 隐私政策

生效日期：2026-10-09

1. 我们收集什么

我们不收集任何可识别到您个人的信息。您对本应用的所有使用行为——点击按钮打点、修改日目标、翻看历史、翻看周曲线、切换外观、导出 CSV——都在您本机设备内完成，不会被记录、不会被上传。

本应用是饮水记录工具，所使用的饮水量 / 日目标 / 时间戳均为您自行输入或由本应用在您点击按钮时记录的本地数据，不包含任何医疗诊断或饮水摄入推荐。本应用的所有数据和功能仅为您个人作记录和回顾用途，不构成任何医疗建议——请根据您的实际身体状况和医生建议合理饮水。

2. 数据存储

您在本应用中产生的所有内容——饮水打点记录、日目标、本地偏好（外观模式）——都仅存储在您本机设备的应用沙盒目录中（通过 shared-kit 的 PrefsStore），不会上传到任何服务器，不与任何第三方共享。

卸载本应用将一并清除所有本地饮水记录与偏好数据。

当您在设置页主动点击"导出 CSV"、或在历史页 / 单日明细页主动点击"导出 CSV"时，本应用会在您的设备下载目录生成 CSV 文件（waterring-entries-YYYYMMDD.csv / waterring-entries-YYYYMM.csv / waterring-entries-all.csv）。这些文件由您自行持有和使用，本应用不会主动读取、上传或分享它们。

3. 第三方 SDK

本应用不集成任何第三方 SDK（无广告 SDK、无统计分析 SDK、无崩溃上报 SDK、无社交分享 SDK、无推送 SDK、无账号登录 SDK、无地图 SDK、无健康 SDK）。

4. 权限说明

本应用不申请任何敏感权限。

本应用不申请：

  • 不申请网络权限（无联网能力，不发任何 HTTP / WebSocket 请求）
  • 不申请位置权限
  • 不申请相机 / 麦克风权限
  • 不申请存储读写权限（CSV 写入下载目录由系统文件 API 完成，不触敏感存储权限）
  • 不申请日历读写权限
  • 不申请通知权限（无饮水到点提醒、无"你今天少喝了"提醒；您主动打开 app 记录）
  • 不申请传感器权限
  • 不申请健康数据权限（不读取 / 不写入系统 Health 数据）
  • 不申请后台常驻权限

5. 您的权利

  • 查看：您对本应用的使用无需任何账号，您的所有饮水记录与偏好设置均在 app 内可见
  • 修改：饮水打点可长按单条删除；日目标可随时调整；外观可随时切换
  • 导出：历史页 / 单日明细页 / 设置页均可导出 CSV 到系统下载目录（UTF-8）
  • 彻底清除：卸载本应用将删除全部本地数据，无服务器备份
