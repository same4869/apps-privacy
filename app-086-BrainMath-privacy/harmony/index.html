脑算营 隐私协议

版本：v1.0.0 生效日期：2026-10-10 适用应用：脑算营（BrainMath） 开发者联系：119123059@qq.com

本协议说明脑算营这款应用会（和不会）如何处理你的数据。

一、我们收集什么

什么都不收集。 脑算营是一款 100% 本地单机应用。

  • 不收集账号信息（本应用没有账号功能）
  • 不收集设备标识符（IMEI / IDFA / OAID / MAC / UUID / 等）
  • 不收集位置信息
  • 不收集通讯录 / 日历 / 相册 / 短信 / 通话记录
  • 不收集任何系统传感器数据
  • 不收集任何埋点 / 行为 / 性能数据

二、我们如何处理你本地的训练记录

你的每次答题流水与终身统计（训练次数 / 答题数 / 正确数 / 用时 / 各难度最佳成绩），仅保存在你本机的 Preferences 存储中，仅本应用可访问。

  • 不上传到任何服务器
  • 不发送到任何第三方 SDK
  • 不写入系统共享区

你随时可以在"我"页面点"清空所有记录"把它们全部抹除。卸载应用时也会自动清空。

三、我们如何处理网络

本应用全程不联网。 没有初始化网络请求、没有后台拉取、没有埋点上传、没有 OTA 更新通道。应用启动后未请求任何系统网络权限。

四、未成年人与"训练工具非游戏"声明

脑算营是一款心算训练工具，不是游戏：

  • 没有角色扮演 / 剧情 / 虚拟物品
  • 没有积分商城 / 虚拟货币 / 内购 / 广告
  • 没有排行榜 / 社交对战 / 聊天
  • 答对/答错只在本机本次训练中反馈，不涉及奖励机制

本应用适合所有年龄段使用，包括未成年人作为学习辅助。若未成年人独立使用本应用，建议由监护人在旁了解应用形态；本应用自身不收集年龄信息，也无法区分成年与否。

五、第三方 SDK 清单

空。 本应用不集成任何第三方 SDK（含统计 / 推送 / 广告 / 支付 / 分享 / 社交登录等类别）。

六、我们不发送通知

本应用不请求通知权限，不发送任何系统通知。即便你开着"每日训练"的想法，本应用也不会主动提醒——这是设计约束。

七、变更

若未来版本改变数据处理方式，会在应用更新说明中告知，并同步更新本协议版本号与生效日期。

八、联系我们

对本协议有任何疑问，请发邮件至 119123059@qq.com。
