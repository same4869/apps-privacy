浇水表 隐私政策

生效日期：2026-10-10

1. 一句话总结

浇水表完全离线运行。它不联网、不发系统通知、不采集任何个人信息、不接任何园艺或气象 API。你的植物档案和浇水记录只存在你自己的手机上。

2. 我们不收集什么

  • 不收集姓名 / 身份证 / 手机号 / 账号信息
  • 不收集定位 / 相册 / 相机 / 麦克风
  • 不收集设备 ID / IMEI / MAC
  • 不收集浏览历史 / 使用行为日志
  • 不接任何第三方 SDK / 统计 / 推送 / 广告

3. 本机存了什么

你新建的植物档案（盆名、植物种类、周期天数、上次浇水日期、备注、保存时间）通过系统 Preferences 存在本机沙盒。卸载应用会清除所有本机数据。

4. 网络 / 通知权限

本应用不申请系统通知权限、不发任何提醒；申请的网络权限（如有）仅用于鸿蒙系统基本运行要求，不发起任何业务请求。

5. 园艺建议免责

  • 本应用仅做周期日历提醒，不代表植物真实需水情况
  • 实际浇水频率受季节 / 盆土 / 光照 / 房间湿度影响很大，请结合自己的观察
  • 不作任何园艺咨询 / 植物养护专业建议

6. 未成年人保护

本应用面向一般用户，不针对 14 岁以下未成年人，不采集任何可识别未成年人身份的信息。

7. 变更

隐私政策如有更新会随应用版本一并发布。使用本应用即视为同意最新版本。
