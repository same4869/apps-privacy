假日倒数 隐私政策

生效日期：2026-10-09

1. 我们收集什么

我们不收集任何可识别到您个人的信息。您对本应用的所有使用行为——查看倒数、浏览节日时间轴、查看调休日历、开关本地提醒——都在您本机设备内完成，不会被记录、不会被上传。

2. 数据存储

本应用使用的法定假日节日表（例如 2026 年、2027 年的节日 / 连休 / 调休数据）作为静态 JSON 文件内置于安装包中，由应用从本地读取，不从任何服务器拉取。

您在应用内设置的本地偏好——外观（Light / Dark / Auto）、提醒偏好（提前 1 / 3 / 7 天）、每个节日的提醒开关——仅存储在您本机设备的应用沙盒目录中，不会上传到任何服务器，不与任何第三方共享。卸载本应用将一并清除所有本地偏好数据。

3. 第三方 SDK

本应用不集成任何第三方 SDK（无广告 SDK、无统计分析 SDK、无崩溃上报 SDK、无社交分享 SDK、无推送 SDK）。

4. 权限说明

本应用仅在您主动开启"节前提醒"功能时申请一项权限：

  • 通知权限（ohos.permission.NOTIFICATION_CONTROLLER 或 reminderAgentManager 相关权限）：仅用于在您本机设备上，在节日前 1 / 3 / 7 天（您可配置）触发一条本地通知，提示您"节日还有 N 天"。通知内容仅在您的设备本机生成和展示，不经任何服务器。您随时可以在应用内关闭所有节日的提醒开关，或在系统设置中撤销通知权限；撤销后应用其余功能不受影响。

本应用不申请：

  • 不申请位置权限（不记录您在哪里）
  • 不申请网络权限（无联网能力）
  • 不申请相机 / 麦克风 / 存储读写权限
  • 不申请日历读写权限（不会往您的系统日历写入事件）

5. 您的权利

  • 查看：您对本应用的使用无需任何账号，您的所有本地偏好都在"设置与关于"中可见
  • 修改：外观 / 提醒偏好 / 单个节日的提醒开关都可随时切换
  • 彻底清除：卸载本应用将删除全部本地偏好与已挂载的本地提醒事件，无服务器备份
