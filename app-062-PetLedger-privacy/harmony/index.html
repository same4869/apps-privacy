宠物账本 隐私政策

生效日期：2026-10-09

1. 我们收集什么

我们不收集任何可识别到您个人的信息。您对本应用的所有使用行为——建立宠物档案、记录消费流水、填写疫苗 / 驱虫日程、查看本月汇总、导出 CSV——都在您本机设备内完成，不会被记录、不会被上传。

本应用不要求也不支持注册 / 登录；不存在任何账号体系，不接入任何第三方 OAuth。

2. 数据存储

您在应用内创建的所有数据——宠物档案（名字 / 物种 / 备注）、消费流水（宠物 / 类目 / 金额 / 日期 / 备注）、疫苗与驱虫日程（名称 / 下次日期 / 备注）、本地偏好（外观 Light / Dark / Auto）——仅存储在您本机设备的应用沙盒 PrefsStore 中，不会上传到任何服务器，不与任何第三方共享。

CSV 导出功能生成的文件写入应用沙盒 Downloads/ 子目录，仍属于本应用在您本机设备上的私有存储空间；本应用不会主动将该文件分享到微信 / QQ / 邮件 / 云盘等任何外部应用，也不唤起系统分享面板。您可以自行在系统"文件管理"中查看 / 拷贝 / 删除该文件。

卸载本应用将一并清除所有本地宠物档、流水、日程与偏好数据。

3. 第三方 SDK

本应用不集成任何第三方 SDK：

  • 无广告 SDK
  • 无统计分析 SDK（无友盟 / 无 TalkingData / 无 Firebase Analytics）
  • 无崩溃上报 SDK
  • 无社交分享 SDK
  • 无推送 SDK
  • 无地图 / 定位 SDK
  • 无支付 SDK

4. 权限说明

本应用不申请任何需用户授权的敏感权限：

  • 不申请网络权限（本应用无联网能力）
  • 不申请通知权限（本应用不发送任何系统通知；疫苗 / 驱虫日程的"到期"由您主动打开 app 查看）
  • 不申请位置权限
  • 不申请相机 / 麦克风权限
  • 不申请存储外部读写权限（CSV 仅写入应用沙盒 Downloads 子目录）
  • 不申请日历读写权限
  • 不申请通讯录读写权限

5. 关于疫苗与驱虫日程档案

本应用的"疫苗 / 驱虫日程"模块仅是用户自己填写的日程档案——您输入"名称 + 下次日期 + 备注"3 个字段后，应用按日期倒计天数展示在您本机设备上。本应用：

  • 不预制任何疫苗 / 驱虫条目库
  • 不提供任何医疗相关建议或指导
  • 不与任何医疗 / 兽医服务打通
  • 不触发任何系统通知或本地提醒

该模块承载的数据与消费流水同处应用沙盒 PrefsStore，不上传、不共享。

6. 您的权利

  • 查看：您对本应用的使用无需任何账号，所有数据都在当前宠物的主区列表与侧抽屉中可见
  • 修改：所有宠物档 / 流水 / 日程 / 偏好均可随时编辑或删除
  • 彻底清除：卸载本应用将删除全部本地数据（包括沙盒 Downloads 内的 CSV），无服务器备份

7. 适用范围

本政策适用于本应用（鸿蒙单机版）全部功能。本应用无 Web 端、无其它平台版本、无云端服务。
