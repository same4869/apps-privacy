浇花打卡本 隐私政策

版本：1.0.0 生效日期：2026-10-12 开发者：ccflower713 联系邮箱：ccflower713@163.com

一、我们是谁

浇花打卡本（以下简称"本应用"）是一款完全离线的本地家庭植物浇水档案记录器。本应用由开发者 ccflower713 独立开发，没有运营团队、没有服务器、没有后台。

二、我们收集什么

什么都不收集。 本应用在你手机上记录的所有信息（植物名、位置标签、浇水间隔天数、每一次浇水的时间戳），完完全全只在你手机本地保存。

  • 不采集设备 ID / IMEI / MAC / 广告 ID
  • 不采集地理位置 / 定位信息
  • 不采集通讯录 / 短信 / 相册 / 相机
  • 不采集浏览历史 / 使用时长 / 功能使用频次
  • 不采集任何形式的用户画像信息
  • 不接入任何第三方 SDK（无广告 SDK、无统计 SDK、无 Push SDK）

三、数据存储位置

你在本应用里添加的所有盆档和浇水动作记录，都通过系统 preferences 接口写在你手机的本应用沙箱内（路径：应用私有空间 el2/base/preferences/）。

  • 任何其他应用都读不到
  • 不同步到云、不同步到任何服务器、不同步到你的其他设备
  • 卸载本应用 = 所有数据自动清空
  • 应用内"关于 → 清空所有数据"按钮 = 立即清空所有盆档和历史

四、网络连接

本应用全程零联网。 已在 Harmony module.json5 的 requestPermissions 中声明无 ohos.permission.INTERNET 等任何联网权限。如果你的手机联网状态下打开本应用，它也绝不会往外发出任何请求。

五、植物名和位置标签说明

本应用的"植物名"（例如你输入的"绿萝"）和"位置"（例如"客厅窗台"）字段，是你为了方便自己辨认而给每盆植物贴的本地标签。这些文字：

  • 不发布到任何平台
  • 不展示给除你以外的任何人
  • 不同步到任何服务器
  • 本应用不是植物养护社交平台、不是 UGC 内容平台
  • 8 个预设植物名（绿萝 / 多肉 / 吊兰 / 虎皮兰 / 发财树 / 龟背竹 / 芦荟 / 君子兰）仅用于首次使用时帮助你快速开始，可随意覆盖

六、权限清单

本应用申请的系统权限：无。

七、未成年人保护

本应用不收集任何个人信息，故对未成年人不构成任何隐私风险。本应用适合全年龄段使用（审核分级建议 4+）。

八、政策变更

若本政策发生变更，新版本会在"关于"页展示新的生效日期。继续使用即视为接受新政策。
