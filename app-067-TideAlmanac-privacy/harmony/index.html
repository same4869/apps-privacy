潮汐历 隐私政策

生效日期：2026-10-09

1. 我们收集什么

我们不收集任何可识别到您个人的信息。您对本应用的所有使用行为——切换港口、收藏/取消收藏港口、查看今日高低潮时刻表、查看 24 小时潮位曲线、翻月历查看某日摘要、切换外观、导出 CSV——都在您本机设备内完成，不会被记录、不会被上传。

本应用是潮汐参考工具，所使用的港口位置、调和常数（M2 / S2 / N2 / K1 / O1 等）均为公开水文天文参数，不包含任何商业水文数据或气象预报内容。本应用的潮位预测结果为近似天文潮汐历，仅供钓鱼 / 赶海 / 沿海生活等休闲用途参考，不构成任何航行安全建议——实际航行请以海事部门官方潮汐表为准。

2. 数据存储

您在本应用中产生的所有内容——收藏的港口清单、最近选择的港口、本地偏好（外观模式、默认起始港口、是否显示米制 / 英制潮高）——都仅存储在您本机设备的应用沙盒目录中（通过 shared-kit 的 PrefsStore），不会上传到任何服务器，不与任何第三方共享。

本应用内置的 200+ 港口调和常数参数（存储于应用安装包随应用一同分发的 rawfile/ports.json）为公开水文天文数据，不随您使用而变化，也不包含任何可识别到您个人的信息。

卸载本应用将一并清除所有本地收藏、港口切换记录与偏好数据。

当您在设置页主动点击"导出全部数据"、或在今日 / 月历页主动点击"导出本月 CSV"时，本应用会在您的设备下载目录生成 CSV 文件（tidealmanac-tides-<港口>-YYYYMM.csv）。这些文件由您自行持有和使用，本应用不会主动读取、上传或分享它们。

3. 第三方 SDK

本应用不集成任何第三方 SDK（无广告 SDK、无统计分析 SDK、无崩溃上报 SDK、无社交分享 SDK、无推送 SDK、无账号登录 SDK、无地图 SDK、无气象 SDK）。

4. 权限说明

本应用不申请任何敏感权限。

本应用不申请：

  • 不申请位置权限（港口由您在列表中主动选择；本应用从不读取您真实的地理位置）
  • 不申请网络权限（无联网能力，不发任何 HTTP / WebSocket 请求；所有潮位预测由本地调和分析公式即时计算）
  • 不申请相机 / 麦克风权限
  • 不申请存储读写权限（CSV 写入下载目录由系统文件 API 完成，不触敏感存储权限）
  • 不申请日历读写权限
  • 不申请通知权限（无潮位到点提醒、无高低潮通知；您主动打开 app 查看）
  • 不申请传感器权限
  • 不申请后台常驻权限

5. 您的权利

  • 查看：您对本应用的使用无需任何账号，您的所有收藏港口、偏好设置均在 app 内可见
  • 修改：收藏港口可随时添加 / 移除；外观 / 默认港口 / 米英制可随时切换
  • 导出：设置页"导出全部数据"可一键导出当前所有收藏港口当月的潮汐表到系统下载目录（UTF-8 CSV）；今日 / 月历页"导出本月 CSV"可仅导出当前港口当月数据
  • 彻底清除：卸载本应用将删除全部本地收藏与偏好数据，无服务器备份
