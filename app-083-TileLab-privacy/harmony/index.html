组件工坊 隐私协议

版本：v1.0.0 生效日期：2026-10-10 适用应用：组件工坊（TileLab） 开发者联系：119123059@qq.com

本协议说明组件工坊这款应用会（和不会）如何处理你的数据。

一、我们收集什么

什么都不收集。 组件工坊是一款 100% 本地单机应用。

  • 不收集账号信息（本应用没有账号功能）
  • 不收集设备标识符（IMEI / IDFA / OAID / MAC / UUID / 等）
  • 不收集位置信息
  • 不收集通讯录 / 日历 / 相册 / 短信 / 通话记录
  • 不收集任何系统传感器数据
  • 不收集任何埋点 / 行为 / 性能数据

二、我们如何处理你本地输入的数据

你在应用内创建的瓦片样式（名称、底色、字色、强调色、圆角、字号梯、便签文字、倒计时目标日 / 标签），仅保存在你本机的 Preferences 存储中，仅本应用可访问。

  • 不上传到任何服务器
  • 不发送到任何第三方 SDK
  • 不写入系统共享区
  • 不写入到桌面小组件 / 服务卡片（见下文第四条）
  • 卸载应用时，所有数据随之彻底删除

三、我们是否连接网络

不连接。 组件工坊应用启动到关闭的整个生命周期不发起任何网络请求。

  • 不接入任何统计 SDK（无友盟、无 Firebase、无华为 AGC Analytics）
  • 不接入任何广告 SDK
  • 不接入任何推送 SDK
  • 不接入任何崩溃上报 SDK
  • 不读取任何在线资源 / 远程配置
  • "天气"瓦片是纯样式占位，固定显示 "多云 23°C"，不读取定位、不请求天气接口

四、非桌面小组件 / Form 服务声明

本应用的"组件"二字仅指应用内渲染和预览的信息瓦片样式。本应用：

  • 不注册 FormExtensionAbility
  • 不下发 任何桌面小组件 / 服务卡片
  • 不占用 桌面卡槽、不出现在系统小组件市场
  • 不读取 桌面 / 锁屏 / 负一屏任何系统状态

你保存的所有瓦片样式都仅能在应用内查看，不会出现在你的手机桌面或锁屏上。想分享可以手动截图。

五、我们是否共享数据

不共享。 因为我们没有收集任何数据。

六、权限清单

组件工坊不申请以下任何权限：

  • 位置
  • 通讯录 / 短信 / 通话 / 日历
  • 相册 / 存储
  • 摄像头 / 麦克风
  • 蓝牙 / NFC
  • 读 / 写系统设置
  • 后台运行 / 自启动
  • 通知推送
  • 悬浮窗
  • 可访问性服务

应用唯一需要的是本地 Preferences 存储（鸿蒙系统默认授予，无需弹窗）。

七、未成年人保护

本应用不面向 14 周岁以下未成年人独立使用。应用内无社交、无 UGC、无评论、无私聊、无广告、无诱导消费、无付费内容。全部功能本地完成，不涉及金钱与社交。

八、协议更新

如本协议有变更，新版本会随应用更新一起下发。你可以在"我 → 隐私协议"查看当前版本。
