时光信 隐私政策

生效日期：2026-10-08

时光信（下称"本应用"）是一款完全本地运行的信件胶囊工具。我们非常重视您的隐私，本政策说明我们不收集什么，以及您写下的信件如何被保管。

1. 我们收集什么

我们不收集任何可识别到您个人的信息。本应用不请求您的姓名、手机号、邮箱、位置、通讯录、设备 ID、广告 ID、IMEI、IDFA、或任何同类标识符。

您在本应用内创建的所有内容（信件标题、正文、收件人昵称、开封日、草稿、外观设置等）均由您在本机输入，不离开您的手机。

2. 数据存储

您的所有数据 100% 存储在您本机的应用沙箱中（鸿蒙 preferences / 文件系统），不联网、不上传、不同步到任何云端。

对于"等待中"尚未到开封日的信件，本应用会做本地加密存储——即使设备被物理访问，也无法从应用文件直接读到信件正文。本地加密的密钥由应用在本机生成并保存在应用自身的加密偏好区，不离开设备。

卸载本应用将同时清空全部信件数据，无任何残留。

3. 第三方 SDK

本应用不集成任何第三方 SDK。不含统计、分析、广告、推送、崩溃上报、A/B 测试、热更新、人脸识别、支付等任何第三方组件。

4. 权限说明

本应用不申请任何敏感权限。不请求定位、相机、麦克风、通讯录、日历、通知、读写外部存储等。应用正常运行所需的本地文件读写，全部限制在应用自身沙箱内，不触碰共享存储。

您在"我的 → 导出我的信件"中调起系统文件选择器把信件导出到外部位置时，是您本人的一次性选择，本应用不会在该操作外读写外部存储。

本应用不属于医疗或心理咨询产品，所记录的信件内容仅为您自愿输入的个人文本，不构成任何健康建议或诊疗依据。

5. 您的权利

因为我们不存储您的任何数据到云端，所以不涉及"向他人索要数据"的流程。您可以：

  • 导出：在"我的 → 导出我的信件"中把全部信件（已开封、等待中、草稿）导出为 JSON 或纯文本文件；您可随时自行查阅、复制、迁移这些文件。
  • 删除：在信箱内长按已开封信件可单条删除；在信件开封后的阅读页溢出菜单也提供删除入口；或直接卸载本应用，一次清除全部本地数据。
  • 停用：直接停用或卸载本应用，不会留下任何残余。

本应用不涉及个人数据跨境传输、不涉及未成年人个人信息的收集。
