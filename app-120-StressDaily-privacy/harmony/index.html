压力值 隐私协议

生效日期：2026-10-10 开发者：压力值开发团队 联系邮箱：119123059@qq.com

一、总则

本应用（下称"本应用"）是一款个人压力值自评与日历记录工具。本应用全程完全 离线运行；本协议向您说明本应用的信息处理方式与承诺。

二、我们不收集哪些信息

本应用：

  • 不采集您的姓名、手机号、位置等任何可识别到个人的信息
  • 不读取任何通讯录、相机、麦克风、相册、定位、日历、短信
  • 不接入心率、血压、睡眠或任何系统传感器
  • 不请求任何系统权限
  • 不连接任何服务器；App 内所有网络请求代码均不存在
  • 不使用任何第三方 SDK（无广告 SDK、无统计 SDK、无推送 SDK）
  • 不要求您注册或登录账号

三、我们存储哪些信息（仅在您本机）

本应用只在您的手机本地的 Preferences 存储区中保存以下极少量信息：

  • 您为每日提交的 1-5 分数值与可选的一句话触发源文本
  • 您在"外观"等设置项中的本地选择

不保存任何可识别到个人的信息；不包含任何视频、照片、生理数据。

四、关于心理与医学建议的声明

本应用是一款个人情绪手动记录工具：

  • 不作任何医学建议、心理诊断、情绪强度评估
  • 不构成 PHQ-9 / GAD-7 / SCL-90 等任何量表或替代
  • 不接入任何心理学硬件或 API
  • 若您的情绪或压力持续影响生活，请咨询持证的心理咨询师或精神科医生

五、数据的生命周期

  • 您卸载本应用时，本地的所有记录会跟随应用一起从您的设备中删除
  • 没有任何方式会将这些数据传输到本应用的开发者或任何第三方

六、未成年人保护

本应用是通用工具，不含任何不适宜未成年人的内容。本应用不针对未成年人 提供特殊服务。建议由监护人决定是否允许未成年人使用。

七、免责声明

本应用是个人情绪手动记录本；不作任何医学建议、心理诊断、情绪 强度评估；若您的情绪或压力持续影响生活，请以精神科医师或持证心理 咨询师的面诊建议为准。

八、协议变更与联系

本协议如有变更，会随应用版本一同在本页面更新。若您对本协议有任何疑问， 请发邮件至：119123059@qq.com。
