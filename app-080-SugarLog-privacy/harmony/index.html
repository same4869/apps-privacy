糖摄账 隐私政策

更新日期：2026-10-10 版本：1.0.0 适用应用：糖摄账（Bundle: com.xun.sugarlog） 开发者：糖摄账开发团队 联系邮箱：119123059@qq.com

---

本政策说明「糖摄账」如何处理你在使用本应用时产生的信息。我们的核心承诺很简单：本应用零相机 / 零 OCR / 零 AI / 零定位 / 零账户 / 零联网 / 零推送 / 零 Scheme 跳转 / 零医疗断言；不收集、不上传、不共享任何用户数据，也不接入任何第三方 SDK。

---

一、我们处理的信息

本应用所处理的全部信息都保存在你的本机 Preferences 中，仅供本应用自身读取：

  • 食物摄入条目（你本人在添加页点选的食物名、份数、糖克数、时刻，上限 2000 条）
  • 自定义食物（你本人手动输入的食物名、分类、份量描述、每份糖克数，上限 50 条）
  • 日警戒值设置（你本人填写的数字，默认 25）
  • 隐私政策的首启同意状态

以上信息均由你本人在本应用内手动输入或点选产生，离开本机不存在任何副本。本应用不基于传感器 / 位置 / 相册 / 任何 AI 分析来自动生成或修改以上信息。

二、我们不做的事（硬承诺）

本应用：

  • 零相机：不启用摄像头、不扫描、不做任何图像识别或 OCR
  • 零 OCR：不做任何文字识别或条码识别（不扫食品条码）
  • 零 AI：不接入任何 AI 大模型、不做任何自动分析 / 自动推荐 / 自动营养建议
  • 零账户：不接入任何云端账号 / 第三方登录体系（不支持微信、华为、Apple、钉钉、飞书登录）
  • 零联网：不上传任何用户数据到服务器 —— 本应用无服务器组件、无云端存储
  • 零社区：不做分享、晒卡、评论、@某人、公开墙任何形式
  • 零电商：不接入任何购物商城 / 下单 / 支付 / 推广链接
  • 零推送：不建立任何提示通道、不建系统闹钟、不接 HMS Push、不震动、不发声
  • 零 Scheme 跳转：不跳转到任何外部 app（微信 / 浏览器 / 邮件）
  • 零医疗断言：本应用仅为用户本人手动输入食物条目的本地日志工具；不提供任何医疗建议、健康诊断、减重方案、血糖估计、营养干预或与之相关的任何提示；预置食物的糖含量仅作一般公开参考，不构成营养学专业意见
  • 零定位：不请求任何位置权限
  • 零传感器：不读取加速度 / 陀螺仪 / 蓝牙 / NFC / 心率 / 血糖仪
  • 零健康数据接入：不读取、不写入系统 Health 服务、不与任何第三方健康 app 交互
  • 不请求任何敏感系统权限：
  • 不请求相机权限（CAMERA）
  • 不请求定位权限（LOCATION）
  • 不请求麦克风权限（MICROPHONE）
  • 不请求通讯录权限（CONTACTS）
  • 不请求日历权限（CALENDAR）
  • 不请求存储管理权限（STORAGE_MANAGE）
  • 不请求通知权限
  • 不请求运动数据权限
  • 不请求医疗数据权限
  • 不接入任何第三方 SDK（无广告 SDK、无统计 SDK、无崩溃 SDK、无推送 SDK、无 AI SDK）
  • 不展示任何形式的广告
  • 不收集任何可识别到个人身份的信息（无账号 ID / 无手机号 / 无邮箱 / 无 IDFA / 无 OAID / 无设备指纹）

三、数据存储与安全

  • 存储位置：鸿蒙系统 Preferences，位于本应用在系统分配的私有沙箱目录内
  • 存储格式：明文 JSON（食物条目与糖克数不属于敏感个人信息，无加密必要；但也请你不要在自定义食物名中填写任何敏感隐私内容）
  • 访问范围：仅本应用自身，其它应用无法访问
  • 卸载清理：卸载本应用时，系统会同步清除本应用的全部沙箱数据

四、数据删除

  • 单条摄入条目：今日列表长按一条 → 删除 → 二次确认
  • 单条自定义食物：设置页 - 自定义食物管理 → 滑动删除
  • 清空全部条目：设置页相应入口，二次确认
  • 全部应用数据：在系统设置中卸载本应用；本应用无服务器端数据，无需额外的"远端删除"流程

五、未成年人保护

本应用不收集任何个人信息，因此也不单独针对未成年人进行信息收集。本应用面向希望做本地糖分摄入记录的所有用户，内容由用户本人手动输入产生。本应用不对未成年人提供任何营养或医疗建议。

六、政策变更

若本政策发生变更，新版本会随应用更新一起下发，更新日期会体现在本页顶部。重大变更会在首启再次弹出同意框。
