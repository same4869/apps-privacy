读书批注本 隐私政策

生效日期：2026-10-12

1. 一句话总结

读书批注本完全离线运行。它不联网、不发系统通知、不播放任何音频、不采集任何个人信息、不接任何第三方 API。您添加的每一本书（书名、作者、是否已读）和每一条批注（摘录内容/感想内容/所在章节/时间戳）全部存在本机 Preferences，卸载应用会清除。导出功能通过系统剪贴板完成，复制的内容只到您主动粘贴的目标应用，本应用不记录任何导出历史。

2. 我们不收集什么

  • 不收集姓名 / 身份证 / 手机号 / 账号信息
  • 不收集定位 / 相册 / 相机 / 麦克风
  • 不收集设备 ID / IMEI / MAC
  • 不收集使用行为日志 / 查询历史 / 批注内容
  • 不接任何第三方 SDK / 统计 / 推送 / 广告
  • 不对您的批注做 AI 分析 / 聚类 / 情感识别

3. 本机存了什么

应用在系统 Preferences 中保存以下内容：

  • 您添加的每一本书（书名、作者、是否已读、创建/更新时间戳）
  • 您添加的每一条批注（类型"摘录/感想"、章节、内容、关联批注 id、时间戳）
  • 外观偏好（light / dark / 跟随系统）
  • 是否已同意本隐私政策

所有数据仅保存在本机，不同步、不上传、不共享。卸载应用会清除所有本机数据。

4. 系统剪贴板

"导出"功能会将单本书批注的 markdown 全文写入系统剪贴板，供您粘贴到任意外部应用（如微信、备忘录、笔记工具）。本应用不记录任何导出历史，剪贴板内容的后续使用取决于您粘贴到的目标应用，与本应用无关。

5. 网络 / 通知 / 音频 / 相机 权限

本应用不申请系统通知权限、不播放任何音频、不读取相机 / 相册 / 位置 / 麦克风，也不发任何业务网络请求；申请的网络权限（如有）仅用于鸿蒙系统基本运行要求。

6. 批注仅为个人学习备忘

  • 本应用是读书批注工具，仅记录您主动输入的文字，不替代专业文学评论或学术引用规范
  • 不涉及任何宗教 / 命理 / 占卜内容

7. 未成年人保护

本应用面向一般成年用户，不针对 14 岁以下未成年人。应用本身不采集任何可识别未成年人身份的信息。

8. 变更

隐私政策如有更新会随应用版本一并发布。使用本应用即视为同意最新版本。
