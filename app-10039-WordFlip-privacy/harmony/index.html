翻词卡 隐私政策

欢迎使用「翻词卡」（以下简称"本应用"）。本应用由 ccflower713 开发并运营，我们非常重视用户的隐私保护。本隐私政策旨在向您说明本应用如何收集、使用、存储和保护您的个人信息。

请您在使用本应用前仔细阅读并充分理解本隐私政策的全部内容。如果您不同意本隐私政策的任何内容，请立即停止使用本应用。您使用本应用即表示您已阅读、理解并同意接受本隐私政策的全部条款。

一、信息收集与使用

本应用不收集任何个人身份信息。本应用是一款纯本地单机应用，所有数据均存储在您的设备本地，不会上传至任何服务器。

1.1 本地存储的数据

本应用在您的设备本地存储以下数据，用于实现应用的核心功能：

  • 词书数据：您创建的词书名称、词条内容（正面/背面文字）、创建时间
  • 学习记录：词条的掌握度评分（陌生/半熟/熟练）、复习时间戳、复习次数
  • 统计数据：每日学习词数、复习次数、学习时长等聚合统计信息
  • 应用设置：您的学习偏好设置（如复习顺序、每日目标、翻卡动画速度）

上述数据均存储在您的设备本地存储空间（HarmonyOS Preferences），不会通过网络传输或分享给任何第三方。

1.2 不收集的信息

本应用明确承诺：

  • 不收集个人身份信息：不收集您的姓名、手机号、邮箱、身份证号等任何个人身份信息
  • 不收集设备信息：不收集您的设备型号、IMEI、MAC地址、IP地址等设备标识信息
  • 不收集位置信息：不获取或使用您的地理位置信息
  • 不收集联系人信息：不访问您的通讯录、短信、通话记录等隐私数据
  • 不收集使用行为数据：不追踪或分析您的应用使用行为、学习内容、浏览记录

二、数据存储与安全

2.1 本地存储

本应用使用 HarmonyOS 系统提供的 Preferences API 进行本地数据存储。所有数据均存储在应用的私有沙箱目录中，其他应用无法访问。

2.2 数据安全措施

  • 物理隔离：数据存储在设备本地，不经过网络传输，天然避免网络劫持和中间人攻击风险
  • 沙箱隔离：应用数据存储在系统分配的私有目录，其他应用无法读取
  • 权限最小化：本应用不申请任何敏感权限（如网络、位置、通讯录、摄像头、麦克风），从根源上杜绝数据泄露风险

2.3 数据备份与导出

本应用提供数据导出功能（导出为 JSON 或 CSV 格式），您可以自主选择是否导出数据以及导出后的存储位置。导出的数据文件由您自行管理和保管，本应用不会自动备份或上传到任何服务器。

三、数据使用目的

本应用收集和使用本地数据的唯一目的是为您提供单词学习和记忆管理服务，具体包括：

  • 展示您创建的词书和词条内容
  • 记录您的学习进度和掌握度评分
  • 根据掌握度提供分级复习功能
  • 统计和可视化您的学习数据（如学习天数、掌握度分布、学习曲线）
  • 保存您的学习偏好设置，提供个性化学习体验

本应用不会将您的任何数据用于上述目的以外的用途，也不会与任何第三方共享您的数据。

四、数据共享与披露

本应用不会与任何第三方共享、出售、出租或交易您的任何数据。

由于本应用是纯本地单机应用，所有数据均存储在您的设备本地，不存在数据传输或共享的技术前提。

4.1 法律要求

在以下情况下，我们可能需要披露您的信息：

  • 根据法律法规、法律程序、诉讼或政府主管部门的强制性要求
  • 为维护本应用的合法权益，如调查可能的违规行为
  • 为保护用户或公众的人身安全或财产安全

但由于本应用不收集个人身份信息，实际上我们无法提供与特定用户关联的数据。

五、用户权利

您对自己的数据享有以下权利：

5.1 访问权

您可以随时在应用内查看您创建的所有词书、词条和学习记录。

5.2 修改权

您可以随时在应用内编辑或删除您创建的词书和词条。

5.3 删除权

  • 您可以在应用内删除单个词条、整个词书或全部学习记录
  • 您可以通过卸载应用的方式彻底删除所有本地数据（卸载后数据无法恢复，请谨慎操作）

5.4 导出权

您可以使用应用提供的数据导出功能，将您的词书数据导出为 JSON 或 CSV 格式文件，自行保存或迁移到其他设备。

5.5 撤回同意权

由于本应用不收集或处理任何个人信息，不存在需要您授权同意的数据处理行为，因此无需撤回同意。

六、未成年人保护

本应用面向所有年龄段用户开放，不主动收集未成年人的个人信息。

由于本应用是纯本地单机应用，不涉及网络交互和个人信息收集，未成年人使用本应用不会面临隐私泄露风险。

如果您是未成年人的监护人，对未成年人使用本应用有任何疑问或顾虑，请联系我们（联系方式见本政策第八条）。

七、隐私政策的变更

我们可能会适时修订本隐私政策。政策更新后，我们会在应用内通过明显方式（如弹窗提示、公告）通知您，并在本隐私政策开头注明最新的更新日期。

重大变更定义：

  • 数据收集范围扩大（如从不收集变为收集某类信息）
  • 数据使用目的改变
  • 数据共享方式改变
  • 您的权利行使方式改变

如果发生重大变更，我们会在应用启动时以弹窗形式征得您的明示同意。如果您不同意变更后的隐私政策，您有权停止使用本应用。
