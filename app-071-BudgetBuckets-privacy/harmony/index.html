预算分桶 隐私政策

更新日期：2026-10-09 版本：1.0.0 适用应用：预算分桶（Bundle: com.xun.budgetbuckets） 开发者：预算分桶开发团队 联系邮箱：119123059@qq.com

---

本政策说明「预算分桶」如何处理你在使用本应用时产生的信息。我们的核心承诺很简单：本应用不收集、不上传、不共享任何用户数据，也不接入任何第三方 SDK。

---

一、本应用是什么

「预算分桶」是一款本机的家庭月度预算分桶（信封法）规划工具。它的功能是帮助你把一个月的生活开支分成 7 个预算桶（食物 / 交通 / 娱乐 / 日用 / 人情 / 孩子 / 其他），追踪每个桶的剩余额度，并在月末把 7 桶没花完的部分合并到一个本机累计数字（"储蓄桶"）。

本应用是预算规划方法论工具，仅做本机数值分配与剩余计算：

  • 不接入任何银行或第三方资金机构接口
  • 不处理实际资金往来 / 不计息
  • 本机的"储蓄桶"仅是一个累计数字，不是任何资金产品

二、我们处理的信息

本应用处理的全部信息都保存在你的本机 Preferences 中，仅供本应用自身读取：

  • 7 个桶的名字和每月上限
  • 你本人手动输入的支出条目（日期 + 事由文本 + 数值 + 所属桶）
  • 桶间互借条目（源桶 + 目标桶 + 数值 + 日期）—— 仅为本机数值字段加减记录
  • 月末结算的本机累计数字
  • 外观偏好（跟随系统 / 浅色 / 深色）
  • 隐私政策的首启同意状态

以上信息均由你本人在本应用内手动录入或开关，离开本机不存在任何副本。

三、我们不做的事（硬承诺）

本应用：

  • 不收集任何个人身份信息（姓名、手机号、身份证、位置等一律不采集）
  • 不接入任何云端账号 / 第三方登录体系（不支持微信、华为、Apple 登录）
  • 不上传任何用户数据到服务器 —— 本应用无服务器组件
  • 不请求任何敏感系统权限：
  • 不请求相机权限
  • 不请求定位权限
  • 不请求麦克风权限
  • 不请求通讯录权限
  • 不请求通知权限
  • 不接入任何第三方 SDK（无广告 SDK、无统计 SDK、无崩溃 SDK、无推送 SDK）
  • 不展示任何形式的广告
  • 不涉及任何对外资金往来（不接银行、不处理实际现金、不计息、不转出）

四、数据存储与安全

  • 存储位置：鸿蒙系统 Preferences，位于本应用在系统分配的私有沙箱目录内
  • 存储格式：明文 JSON（用户自己手动录入的桶名 / 数值 / 事由文本不属于敏感个人信息，无加密必要）
  • 访问范围：仅本应用自身，其他应用无法访问
  • 卸载清理：卸载本应用时，系统会同步清除本应用的全部沙箱数据

五、数据导出与删除

  • 本应用 v1.0.0 不提供数据导出 / CSV 功能（计划在 v1.1 加入）
  • 如需清除全部数据，请在系统设置中卸载本应用；或在本应用内逐条删除桶条目 / 支出条目
  • 本应用无服务器端数据，无需额外的"远端删除"流程

六、未成年人保护

本应用不收集任何个人信息，因此也不单独针对未成年人进行信息收集。本应用面向所有用户开放使用。

七、政策变更

若本政策发生变更，新版本会随应用更新一起下发，更新日期会体现在本页顶部。重大变更会在首启再次弹出同意框。
