心意记 隐私政策

更新日期：2026-10-10 版本：1.0.0 适用应用：心意记（Bundle: com.xun.giftlog） 开发者：心意记开发团队 联系邮箱：119123059@qq.com

---

本政策说明「心意记」如何处理你在使用本应用时产生的信息。我们的核心承诺很简单：本应用零相机 / 零 OCR / 零 AI / 零定位 / 零账户 / 零联网 / 零推送 / 零 Scheme 跳转；不收集、不上传、不共享任何用户数据，也不接入任何第三方 SDK。

---

一、我们处理的信息

本应用所处理的全部数据都保存在你的本机 Preferences 中，仅供本应用自身读取：

  • 你手动录入的礼物条目（方向、对方人名、礼物名、场合、日期、备注）
  • 隐私政策的首启同意状态

以上信息均由你本人在本应用内手动输入或点选产生，离开本机不存在任何副本。本应用不读取你的通讯录，所有"对方人名"均由你手动输入。

二、我们不做的事（硬承诺）

本应用：

  • 零相机：不启用摄像头、不扫描
  • 零 OCR：不做任何文字识别或条码识别
  • 零 AI：不接入任何 AI 大模型、不做任何自动分析 / 自动推荐
  • 零账户：不接入任何云端账号 / 第三方登录体系（不支持微信、华为、Apple、钉钉、飞书登录）
  • 零联网：不上传任何用户数据到服务器 —— 本应用无服务器组件、无云端存储
  • 零社区：不做分享、晒单、评论、@某人、公开墙任何形式
  • 零通讯录：不请求 CONTACTS 权限、不读取、不匹配、不同步任何通讯录数据
  • 零日历：不写入系统日历、不请求 CALENDAR 权限
  • 零电商：不接入任何购物商城 / 下单 / 支付 / 推广链接；本应用不涉及任何金额字段
  • 零推送：不建立任何提示通道、不建系统闹钟、不接 HMS Push、不震动、不发声
  • 零 Scheme 跳转：不跳转到任何外部 app（微信 / 浏览器 / 邮件）
  • 零剪贴板：不读取、不写入系统剪贴板
  • 零定位：不请求任何位置权限
  • 零传感器：不读取加速度 / 陀螺仪 / 蓝牙 / NFC
  • 零文件读写：不读取、不写入任何系统文件或相册，不请求 STORAGE_MANAGE
  • 零附件：不支持图片 / 音频 / 视频附件；条目字段纯文本
  • 不请求任何敏感系统权限：
  • 不请求相机权限（CAMERA）
  • 不请求定位权限（LOCATION）
  • 不请求麦克风权限（MICROPHONE）
  • 不请求通讯录权限（CONTACTS）
  • 不请求日历权限（CALENDAR）
  • 不请求存储管理权限（STORAGE_MANAGE）
  • 不请求通知权限
  • 不请求运动数据权限
  • 不接入任何第三方 SDK（无广告 SDK、无统计 SDK、无崩溃 SDK、无推送 SDK、无 AI SDK）
  • 不展示任何形式的广告
  • 不收集任何可识别到个人身份的信息（无账号 ID / 无手机号 / 无邮箱 / 无 IDFA / 无 OAID / 无设备指纹）

三、非账务工具声明

本应用不是记账 / 财务软件。礼物条目字段不含金额、不含货币、不计算净往来值。请不要把本应用用于：份子钱记录、债务凭证、商业交易凭证、报销凭证。此类场景请使用专门的记账软件。

四、数据存储与安全

  • 存储位置：鸿蒙系统 Preferences，位于本应用在系统分配的私有沙箱目录内
  • 存储格式：明文 JSON
  • 访问范围：仅本应用自身，其它应用无法访问
  • 卸载清理：卸载本应用时，系统会同步清除本应用的全部沙箱数据

五、数据删除

  • 删除单条：详情页"删除"按钮，二次确认
  • 清空全部：设置页"清空全部记录"入口，二次确认
  • 全部应用数据：在系统设置中卸载本应用；本应用无服务器端数据，无需额外的"远端删除"流程

六、未成年人保护

本应用不收集任何个人信息，因此也不单独针对未成年人进行信息收集。本应用面向希望本地记录礼物往来的成年用户，内容由用户本人手动输入产生。

七、政策变更

若本政策发生变更，新版本会随应用更新一起下发，更新日期会体现在本页顶部。重大变更会在首启再次弹出同意框。
