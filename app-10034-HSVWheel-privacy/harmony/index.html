色相环速查 隐私政策

版本：1.0.0 生效日期：2026-10-13 开发者：ccflower713 联系邮箱：ccflower713@163.com

一、我们是谁

色相环速查（以下简称"本应用"）是一款完全离线的本地色相环速查工具。本应用由开发者 ccflower713 独立开发，没有运营团队、没有服务器、没有后台、没有大模型 API 接入。

二、我们收集什么

什么都不收集。 本应用是一款纯静态的色相环速查工具，没有"用户生成记录"这个概念；本机只保存一个"外观偏好"（跟随系统 / 浅色 / 深色），不保存任何其他数据。

  • 不采集设备 ID / IMEI / MAC / 广告 ID
  • 不采集地理位置 / 定位信息
  • 不采集通讯录 / 短信 / 相册 / 相机 / 麦克风 / 加速度传感器
  • 不采集浏览历史 / 使用时长 / 功能使用频次
  • 不采集任何形式的用户画像信息
  • 不接入任何第三方 SDK（无广告 SDK、无统计 SDK、无 Push SDK、无 AI/LLM SDK）
  • 十二色相中英文名、hex 值与五种配色方案（互补 / 三角 / 分裂互补 / 类似 / 四分）均为出厂固定本地字符串常量，不随版本动态下发、不走任何在线接口

三、数据存储位置

本应用唯一会写在你手机本地的信息是"外观偏好"数值（0 / 1 / 2），通过系统 preferences 接口写在你手机的本应用沙箱内（路径：应用私有空间 el2/base/preferences/）。

  • 任何其他应用都读不到
  • 不同步到云、不同步到任何服务器、不同步到你的其他设备
  • 卸载本应用 = 该偏好自动清空

四、权限需求

本应用不申请任何系统权限。你在首次启动时看到的隐私弹窗，仅用于告知你本政策内容并请求你的同意，不涉及任何系统权限授权。

五、第三方

本应用不集成任何第三方 SDK，不走第三方分析、不走第三方广告、不走第三方推送、不走第三方 AI。

六、你的权利

  • 你随时可以在应用内"我的 - 外观"切换外观偏好
  • 你随时可以卸载本应用，所有本地偏好将自动删除
  • 你可以通过邮箱 ccflower713@163.com 联系开发者反馈问题

七、未成年人

本应用非专门面向未成年人设计，但本应用因不收集任何个人信息、不展示用户生成内容、不含任何敏感内容，所以亦适合各年龄段使用者作为色彩学习与设计速查工具。

八、政策变更

若本政策未来发生实质性变更，开发者会通过应用更新说明告知你，并要求你在新版本首次启动时重新同意。

九、联系方式

关于本政策的任何疑问，请发邮件至：ccflower713@163.com
